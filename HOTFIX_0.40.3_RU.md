# LAST BASE 0.40.3 — минимальный Performance Hotfix

Основа: готовая 0.40.2. Save Format 20 без изменения структуры.

- Обычные запросы сохранения объединены в окно 15 секунд. Новые события не отодвигают его бесконечно. После успешного сохранения очередь отменяется; при ошибке запись повторяется позднее. Периодический gameplay pulse только отмечает изменения, а не сериализует мир. Ручное сохранение, смена слота, background/pagehide/beforeunload сохраняют немедленно; backup/recovery сохранены. Принудительное завершение браузера/ОС не гарантирует lifecycle callback.
- MAX_CANVAS_DPR = 2. Изменено только внутреннее разрешение Canvas; CSS и игровые координаты не менялись.
- AK/M4: один светлый tracer длиной 36 игровых единиц, время жизни 75 мс, из фактической точки ствола по направлению выстрела с учётом разброса. Кольцевой пул 24 записи, без DOM и индивидуальных таймеров. Hit/damage mechanics не изменены.
- qa/perf-corrective.cjs: flushTimers, обработка зарегистрированных interval callbacks, целочисленные шаги часов, учёт timer work в измеряемом update. PERF_DEVICE_DPR=3 по умолчанию; PERF_RENDER_DPR=3 позволяет только в harness проверить повышенную render-нагрузку (по умолчанию 2). Production override отсутствует. Результаты содержат фактический Canvas DPR.

Проверено только: пересборка 131 исходного раздела, синтаксис runtime/harness, короткая изолированная sanity-проверка coalescing (1000 запросов → один save через 15000 мс), целостность архива.

Полный regression suite, benchmarks, длительные автотесты и проверки на телефоне НЕ запускались по запросу. Старые результаты в qa/results относятся к предыдущим версиям и не являются результатами 0.40.3. Производительность и визуальное качество tracer требуется проверить вручную на телефоне.

Lighting, AI, Zombies и I1 не перерабатывались. I2 не начинался.
