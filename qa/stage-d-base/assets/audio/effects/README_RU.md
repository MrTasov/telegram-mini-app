# Звуковые эффекты

Polish patch добавляет три внешних mono PCM WAV (44,1 кГц, 16 бит):

| Файл | Назначение | Длительность |
|---|---|---:|
| `footstep_soft_floor.wav` | Мягкий контакт обуви с полом | 0,14 с |
| `chop_wood.wav` | Удар топора по дереву | 0,20 с |
| `mine_rock.wav` | Удар кирки по Stone/Ore/Coal | 0,24 с |

Это оригинальный процедурно созданный foley, подготовленный офлайн. Новый мягкий шаг создаётся скриптом `tools/soft-footstep.py`, два удара — `tools/polish-audio.py`. В игре воспроизводятся готовые файлы. Звуки можно заменять своими записями по тем же путям. Не добавляйте тишину перед ударом: событие запускается на контактной фазе анимации.

Прежний `footstep_boot.wav` оставлен для исторического сравнения и не загружается игрой. Новый путь предотвращает использование старого звука из кэша. `audio.footsteps.volumeScale: 0.5` уменьшает только канал шагов на 50%; остальные эффекты используют прежнюю громкость. Длительность нового WAV не меняется от скорости ходьбы — меняется частота контактных событий общей анимации.

WebAudio разблокируется жестом пользователя. Буферы декодируются один раз. Два ограниченных канала (`step`, `work`) используют постоянные GainNode; короткий BufferSource создаётся только на контакт и отключается после завершения. Остановка, пауза, скрытие страницы и нулевая громкость прекращают соответствующее воспроизведение. Повторный вызов обновления в одном кадре не повторяет звук.

Шесть прежних необязательных файлов — `gunshot.mp3`, `zombie.mp3`, `hit.mp3`, `player_hit.mp3`, `chicken.mp3`, `cow.mp3` — отсутствовали в исходном проекте и остаются optional. Игра не запрашивает отсутствующие файлы. После добавления, удаления или изменения пути выполните `npm run build`, чтобы обновить доступность в Asset Manifest.
