SURVIVAL BASE — 0.20.0

УСТАНОВКА В GITHUB
1. Распакуйте архив.
2. Замените index.html в корне вашего репозитория.
3. Загрузите папку assets с сохранением её структуры. Если assets/v0190 уже есть
   от версии 0.19.1, достаточно добавить новую папку assets/v0200.
4. После обновления GitHub Pages закройте мини-апп в Telegram и откройте заново.

Для запуска игры нужны index.html и assets. Удобно загрузить их в GitHub двумя
действиями: сначала файл, затем папку. Каждый отдельный файл меньше 25 МБ.
Файлы source и qa предназначены для разработки и проверки; игра их не загружает.

ЧТО ИЗМЕНИЛОСЬ
— Внешний периметр: 4 угла, 11 длинных стен и одни широкие южные ворота.
  С каждой стороны три пролёта; южный средний пролёт занят воротами.
— Верхние ворота, входной тамбур с дополнительными воротами и площадки
  под пулемёты убраны. Внутренние стены сохранены.
— Стены стали шире. Укрепления имеют пять разных обликов, углы и лестницы
  выполнены в той же стилистике. Новые изображения находятся в assets/v0200.
— На каждой стороне четыре лестницы, всего 16. Подъём и спуск плавные.
— Со стены можно спрыгнуть только во двор. Внешний край защищён высоким бортиком.
— При 90%, 50% и 20% оставшихся HP последовательно усиливаются трещины.
  При 0 HP секция превращается в проходимый пролом. Это работает и для углов.
— Молот, ремонт и пять уровней HP продолжают работать:
  10 000 / 20 000 / 40 000 / 60 000 / 100 000.
— Пулемёт можно поставить в любой подходящей точке стены и на стыке секций.
  Часть основания должна стоять на стене. Ствол сам по себе опорой не считается.
— Если одна опора разрушена, пулемёт использует соседнюю целую секцию.
  При потере всех опор он становится доступен для подбора; патроны и уровень сохраняются.

СОХРАНЕНИЯ
Сохранения 0.19.1 переносятся автоматически. Объединённая секция получает
наибольший уровень исходных секций и средневзвешенную долю их оставшихся HP
по площади перекрытия. Южные ворота сохраняют свой уровень и HP.
HP внутренних стен, предметы, дрон и содержимое пулемётов сохраняются.
Пулемёт, прежнее место которого стало проёмом, можно подобрать во дворе.

ПРОВЕРКА
Проверены все 16 лестниц, запрет выхода через внешний край, спрыгивание во двор,
проходимость проломов и углов, ремонт, улучшения, крепление/снятие пулемёта,
сохранение и перенос 0.19.1, запуск со старым сохранением, отрисовка и прежние
маркеры целей/исчезновение тел. Отчёты и изображения находятся в qa.
Среда проверки: настоящий JavaScript игры и Canvas2D, модель DOM.
На физическом телефоне внутри Telegram сборка здесь не проверялась.

ИСХОДНИКИ
Изменения локальны: периметр/лестницы, связанные точки света, крепления пулемёта
и перенос сохранений. Сборка: python3 source/build.py.
Основной новый модуль: source/walls020.js. Перенос сохранений: source/migration020.js.
Остальные точечные изменения: source/patch_modules.py, source/build.py.
source/baseline_0.19.1.html содержит исходную рабочую версию для воспроизводимой сборки.

ГРАФИКА
Пять атласов созданы встроенным генератором image_gen.imagegen.
Каждый содержит стену, угол и лестницу соответствующего уровня.
Запросы: source/art_prompts.json. Координаты спрайтов: source/art_frames.json.
Трещины накладываются кодом и не увеличивают размер изображений.
