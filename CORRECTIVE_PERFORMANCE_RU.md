# LAST BASE 0.29.0 — Corrective / Performance Patch 1

Отдельный патч поверх `LAST_BASE_0.29.0_Player_Visual_Fix.zip`. Исходный дизайн персонажа, его масштаб +65%, оружейные параметры, схема управления, меню, переводы и World Events сохранены. Версия формата сохранений — 3; новые поля сохранения не добавлены.

## Исправления и причины

### 1. Движение и совместимые действия

Использована существующая `GameMovement.canMoveWhileActive` и система команд `GameActions` / `GameSimulation`.

В исходной сборке обычный выбор цели, Reload через `click` и открытие Drone UI уже сохраняли маршрут. Проверка выявила другие входы, которые обходили это правило:

- AUTO при смене устройства вызывал `stopControls`, отменяя маршрут даже при совместимом действии. Теперь автоматическая смена адаптера сохраняет движение; явное изменение режима управления по-прежнему освобождает ввод.
- Второе касание зомби во время движения пальцем попадало в обработчик pinch раньше выбора цели. Приоритет выбора цели теперь учитывается до масштабирования. Два касания свободной земли остаются жестом pinch.
- Reload зависел только от `click`. Добавлена активация по отпусканию собственного touch/pen-контакта, в том числе второго пальца, с подавлением повторного compatibility click. Удерживаемый joystick не освобождается.
- Открытая панель блокировала изменения удерживаемого вектора, а движение пальцем переставало получать актуальную точку. Теперь уже начатый ввод продолжает обновляться; новое движение через модальную панель не создаётся.
- Касание доступного совместимого объекта, в том числе дрона, при удерживаемом движении больше не отбрасывается.

Добыча Stone/Ore и рубка Tree останавливают маршрут и движение пальцем/джойстиком. Повторное нажатие на уже обрабатываемое дерево не перезапускает процесс.

### 6–7. Производительность ввода

**Подтверждённая причина №6:** одиночный запрос с обходом препятствия полностью выполнял A* внутри обработчика ввода. Обычный маршрут и повторное планирование после столкновения также могли вызывать синхронный поиск. Удержание пальца уже использовало прямое управление без A*.

Такие запросы переведены на существующий отменяемый генератор маршрута с бюджетом времени на кадр. Прямой свободный путь устанавливается сразу. Если нужен обход, персонаж сразу движется по проверенному короткому участку, пока рассчитывается остальной маршрут. Этот подход уже применялся для карты; теперь выбор безопасного первого участка общий и проверяет каждый новый отрезок один раз. Новый tap заменяет старую незавершённую задачу. Для дверей сохраняются прежние разрешения и физические проверки столкновений. Снимок разрешений теперь ограничивается нужной сценой и один раз используется на весь шаг расчёта, вместо повторного вычисления для каждого вызова генератора.

**№7 проверен отдельно:** при непрерывном удержании над препятствием повторного A* не обнаружено ни до, ни после патча. Этот сценарий не воспроизвёл отдельный скачок времени на стенде. Отпускание пальца над препятствием и взаимодействие с объектом проверены отдельно; тяжёлый расчёт на этих переходах теперь также выполняется по частям.

**Общая причина:** синхронная маршрутизация объясняет дискретные команды и переходы при отпускании пальца, но не подтверждена как причина лага именно во время непрерывного удержания. Исправление такого аппаратного микролага нельзя считать подтверждённым без проверки на телефоне. Задержка ввода и throttling жеста не добавлены.

### 5. Scout Drone

В режиме Attack Target выбранная доступная цель получает приоритет. Без неё, после её смерти, удаления или невозможности занять позицию дрон защищает игрока. Новая выбранная цель снова получает приоритет. Режим UI остаётся Attack Target, боевые характеристики дрона не изменены.

Недоступная цель запоминается до изменения цели/её позиции/геометрии, чтобы не повторять неудачную атаку каждый кадр. Сохранённая команда атаки связывается с прежним врагом через существующий stable ID при загрузке.

Непрерывное удержание в этом замере не стало быстрее: небольшие CPU-затраты movement/context выросли; отдельный скачок над препятствием и повторные A* не воспроизведены. Это ограничивает вывод о пункте №7: нельзя заявлять об устранении именно телефонного лага удержания по результатам данного стенда.

Загрузка изображений: **125 → 125**, уникальных столько же; повторных запросов и runtime errors нет. Дополнительная память тени — 64×64×4 = **16 КиБ**. Это размер RGBA-буфера, не замер полного потребления памяти браузером.

Методика: 25 холодных запросов каждого tap-сценария с очисткой route cache; 360 кадров каждого удержания; 150 отрисовок по 200 зомби, первые 30 разогревочные. До — точная предыдущая сборка из `qa/pre-corrective-performance/`, после — текущая. Рендер-замер изолирован от остального игрового кадра; p95 не означает FPS всей игры. Измерения запускались отдельно от regression suite. Полные p50/p95/max, время Pointer Move и счётчики находятся в `qa/results/corrective-performance-comparison.json`. Воспроизведение: `node qa/corrective-bench.cjs`.

Замеры выполнены на одном стенде с настоящим Canvas2D и моделью DOM. Это не FPS настоящего телефона, браузера или Telegram WebView. При измерении маршрутов бюджет времени использует реальные CPU-затраты внутри шага, а не неподвижное время тестовой фикстуры.

Полный suite сохранён. Исторические эталоны не переписаны: в сравнительных тестах явно учитываются только новый yield стоящих деревьев и добавленные Stone ID. Сам новый баланс проверяется отдельно. Исключения из старых проверок неизменности кода перечислены по конкретным файлам, остальные исходники и все PNG/sprites проверяются по исходным SHA-256.

## GitHub и ручная проверка

Распаковать содержимое ZIP в корень проекта: `index.html`, `assets/`, `js/`, `src/`, `styles/` должны лежать рядом. Готовый `js/game.js` уже собран. Для локальной проверки исходников: `npm ci`, `npm run build`, `npm test`. Запускать через HTTP-сервер. Патч имеет отдельный cache tag `0.29.0-corrective-performance-1`. Для сохранения локальных слотов оставьте прежний адрес сайта (origin) и данные браузера.

На PC и телефоне проверить:

1. Удерживать joystick/палец, выбрать зомби вторым пальцем, перезарядиться и открыть Drone UI. Убедиться, что движение и изменение направления продолжаются, а отпускание первого пальца его останавливает.
2. Сделать одиночные и последовательные taps, пройти вокруг здания. Провести удерживаемый палец по стене, дереву и камню, затем отпустить. Особое внимание — исходному аппаратному микролагу №7.
3. Рубить дерево, добывать камень и руду: персонаж стоит на месте. Новое дерево даёт 10 Wood, рубится за 2,3 секунды.
4. Проверить Attack Target без цели, после её смерти и с новой целью; вручную менять режим на Protect не требуется.
5. Посмотреть тени и corpses на дневной/ночной карте, включая бой с большим числом врагов.
6. Загрузить свой старый слот, сохранить и загрузить снова; проверить Main Menu, EN/RU и оба режима управления.
