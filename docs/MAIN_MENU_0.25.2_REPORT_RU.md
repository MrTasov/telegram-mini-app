# LAST BASE 0.25.2 — Main Menu / Start Screen

Отдельный патч поверх принятой 0.25.1 (Этап 5). Этап 6 не начат.

## Что изменено

При открытии отображается главное меню. До выбора сохранения или новой игры игровой цикл, автосохранение и gameplay input не активируются. Инициализируются общие системы и интерфейс; второй player или второй цикл не создаются.

- **CONTINUE / ПРОДОЛЖИТЬ** выбирает читаемый слот с самым поздним savedAt; при равенстве учитывается прежний активный слот. Используется существующий fallback на резервную копию. Если нет читаемых saves, кнопка недоступна. Новый игровой прогресс через Continue не создаётся. Старое сохранение до системы слотов переносится существующей миграцией только после выбора Continue.
- **NEW GAME / НОВАЯ ИГРА** показывает все пять слотов. Можно выбрать свободный. Для занятого требуется отдельное подтверждение с именем и номером. Отмена ничего не удаляет. Изменение слота в другой вкладке отменяет устаревшее подтверждение. При подтверждённой замене удаляется резервная копия только выбранного старого прогресса.
- **LOAD GAME / ЗАГРУЗИТЬ ИГРУ** показывает номер, имя, дату/время, поверхность/бункер и признак резервной копии. Пустые и нечитаемые слоты обозначены явно. Пользовательские имена не переводятся и выводятся текстом.
- **SETTINGS / НАСТРОЙКИ** открывает существующий интерфейс. Language, Control Mode, звук и доступный fullscreen работают до запуска. Смена English/Русский сразу обновляет меню. Кнопки, требующие текущую игровую сессию, включая сохранение и редактор размещения игровых controls, показываются после входа в игру. Закрытие Settings возвращает к неподвижному Main Menu.
- **EXIT / ВЫХОД** вызывает Telegram.WebApp.close при наличии контекста Telegram. В браузере показывает подсказку закрыть вкладку/окно; window.close не вызывается. Используется [официальный механизм Telegram](https://core.telegram.org/bots/webapps#initializing-mini-apps); браузерный вариант учитывает [ограничения window.close](https://developer.mozilla.org/en-US/docs/Web/API/Window/close).

После успешного выбора меню скрывается, фоновый media-элемент освобождается, а существующий bootstrap запускается один раз. Автосохранение и игровой loop остаются общими. Действия с игровым миром из карты/клавиатуры заблокированы до запуска. Формат saves и их пять ключей не менялись; изменён только обычный номер выпуска 0.25.2 в gameVersion и его whitelist.

## Фоны и оформление

Оба предоставленных PNG сохранены **байт в байт**. Контрольные суммы записаны в qa/main-menu-assets.json и проверены тестами.

| Файл | Размер |
|---|---|
| assets/images/menu/background-portrait.png | 940 × 1672 |
| assets/images/menu/background-landscape.png | 1672 × 941 |

Изображения — внешние assets, зарегистрированные в assets/manifest.json. HTML picture выбирает фон по ориентации окна; пропорции сохраняет object-fit: cover. При обычном запуске браузер выбирает один фон. При повороте может загрузить второй. Логика меню одна для обоих форматов.

Исходные изображения занимают суммарно 6.77 MB; выбранный фон требует приблизительно 6.3 MB несжатых RGBA-пикселей без учёта браузерного кэша и GPU. Это ожидаемая дополнительная стоимость экрана меню, не измерение памяти телефона. Анимированных эффектов или фонового игрового loop на меню нет.

Оформление вынесено в **styles/main-menu.css**:

| Параметр | Landscape | Portrait |
|---|---:|---:|
| --menu-brightness | 0.91 | 0.94 |
| --menu-saturation | 0.72 | 0.73 |
| --menu-contrast | 0.91 | 0.92 |
| --menu-cold-opacity | 0.065 | 0.065 |
| --menu-mist-opacity | 0.09 | 0.07 |
| --menu-ui-x | 50% | 65% |
| --menu-ui-bottom | 5% | 4% |
| --menu-ui-width | до 900px | 58% |
| --menu-button-height | 48px | 44px |

Для небольшого landscape и короткого portrait есть отдельные компактные значения. Safe-area учитывается через env(). На широком экране кнопки идут одним рядом у нижнего края. На portrait — вертикально снизу, правее персонажа. Финальную оценку перекрытия композиции оставляем ручной проверке.

«На 10% светлее» означает умножить brightness каждого формата на 1.1. «Меньше тумана» — уменьшить mist-opacity. Поднять кнопки — увеличить ui-bottom; сдвинуть — изменить ui-x. Редактировать PNG или игровую логику для этого не нужно.

Animated WebP можно подключить через существующий picture. Изолированный MenuBackground в src/ui/main-menu.js содержит конфигурацию и адаптер для будущего video, включая ориентацию, muted/loop/playsInline и остановку после запуска. Сейчас используется только статичное изображение.

## Проверки

**Полный npm test: 10185 успешных проверок, ошибок нет.** Все 20 заданий прошли. Отдельный Main Menu suite: 106 проверок.

Проверены запуск без saves, один/несколько slots, все пять заняты, выбор свободного, подтверждение и отмена замены, изменение слота в другой вкладке, повреждённый primary/рабочий backup, недоступное хранилище и ошибки записи. Проверены Continue/Load/New/Settings/Exit, смена языка, Mouse/Touch-события, отсутствие loop/autosave до выбора, ровно один запуск после выбора, повторные нажатия и неизменность обработчиков при повторном открытии Settings.

75 исторических контрольных файлов Этапов 0/1/2 дополнительно загружены **через Main Menu**, сохранены и загружены повторно. Прежние baseline, сохранения, баланс, interaction fixes, PC/Mobile, ресурсы, Canvas, карта/шкала добычи, EN/RU и сравнения состояния также прошли. Первоначальные 99 игровых изображений не изменялись; добавлены только два фона. Семь необязательных MP3, отсутствовавших ещё в исходной принятой игре, остались отмечены как необязательные; новых отсутствующих ресурсов нет.

Автоматические проверки используют VM с DOM-моделью и настоящий Canvas2D. Старые gameplay suites проходят свой прежний post-launch setup в тестовом harness; отдельный suite меню проверяет реальный начальный экран без этого перехода. Проверки layout подтверждают структуру, CSS-параметры и ссылки; они не являются браузерными screenshots. Настоящую браузерную проверку локальной сборки выполнить не удалось: отдельный браузер запретил file://, локального движка в среде нет. Touch-события моделировались, физический телефон не тестировался. FPS/расход памяти телефона для этого патча не измерялись.

Результаты: qa/results/summary.json и qa/results/main-menu.json. Исторические отчёты Этапов 0–5 сохранены как предыдущие результаты; текущий документ относится к Main Menu patch.

## Ручная проверка и установка

Распаковать архив и обновить содержимое прежнего GitHub-проекта целиком, сохраняя папки. Открывать по прежнему адресу; данные сайта/localStorage не очищать. После обновления убедиться, что версия 0.25.2.

Проверь главное меню в обеих ориентациях, читаемость кнопок и видимость композиции, переключение EN/RU и возврат из Settings, Continue старой игры, выбор New Game и отмену перезаписи, затем обычный gameplay. Краткая инструкция есть в README_RU.md. Этап 6 не начат; дальнейшие изменения ждут ручной проверки.
