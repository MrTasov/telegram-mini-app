# LAST BASE 0.23.1 — PC / Mobile Controls

Отдельный патч поверх принятой 0.23.0. Этап 4 не начат. Одна сборка, один player, один игровой цикл, прежние владельцы gameplay-состояния.

## Режим управления

Settings → CONTROL MODE: AUTO / PC / MOBILE. Переключение работает в текущей игре. AUTO использует pointer/hover, any-pointer/any-hover, maxTouchPoints и фактический pointerType. Ширина экрана не определяет режим. На гибридном устройстве новое касание выбирает MOBILE, мышь или игровая клавиатурная команда — PC; активный жест не переключается вторым указателем. Ручной PC/MOBILE имеет приоритет.

Настройка записывается отдельно в `last_base_control_mode_v1`. Она не является частью персонажа, экспортируемого прогресса или пяти save slots. При запрете localStorage переключение работает до перезагрузки с уведомлением. Повреждённое значение заменяется AUTO.

## PC

| Ввод | Действие |
| --- | --- |
| ЛКМ по свободному месту | Прежний подход к точке |
| Удерживать ЛКМ и двигать мышь | Прежнее следование за указателем; после отпускания — подход к последней точке |
| ЛКМ по объекту | Существующий подход / взаимодействие / открытие интерфейса |
| ЛКМ по врагу | Прежний выбор цели |
| Удерживать ПКМ | Прицел и огонь через существующее оружие; при выбранной цели — по ней, иначе к курсору |
| R | Перезарядка текущего оружия |
| I | Открыть / закрыть инвентарь |
| 1–5 | Выбор существующих быстрых слотов; прежние правила пустых слотов и предметов |
| M | Открыть / закрыть карту |
| C | Существующий тихий ход |
| Esc | Закрыть верхнее окно; в карте сначала убрать фильтры; отменить установку турели; в игре открыть Settings |
| Колесо мыши | Существующий масштаб |

WASD не добавлен. Переименование сохранений и другие поля ввода не перехватываются игровыми shortcuts. Ctrl/Alt/Meta, IME и удержание клавиши не вызывают повторных игровых команд. Окно смерти не закрывается через Esc.

Touch-only джойстики/Fire и Action скрыты, включая их зоны захвата. HP, патроны, быстрые слоты, инвентарь, карта, дрон и остальные игровые показатели сохранены. Инвентарь, тихий ход и перезарядка доступны мышью возле нижней панели; большие окна используют больше места на широком экране. Раскладка MOBILE остаётся прежней.

## Mobile

- Левый джойстик — прежнее аналоговое движение.
- Правый джойстик — прежние прицеливание и стрельба; при выбранной цели — прежний Fire.
- Action / ✋ — ближайшее контекстное действие.
- Перезарядка, инвентарь, быстрые слоты, карта и остальные кнопки сохранены.
- Касание мира — прежний подход, выбор врага и взаимодействие.
- Удержание и ведение пальца — прежнее следование.
- Два пальца на мире — прежний масштаб; джойстики исключены из pinch.
- Редактор расположения и отдельные портретная/альбомная раскладки сохранены.

## Архитектура

`src/input/router.js` владеет общим маршрутизатором Pointer Events и клавиатуры, выбором режима и завершением жестов. При переключении он меняет состояние, а не добавляет второй комплект игровых слушателей.

`src/input/actions.js` переводит ввод в MOVE, AIM, FIRE, INTERACT, RELOAD, SELECT_SLOT, INVENTORY, MAP и другие общие команды. Они вызывают существующие approachPoint/approachObject, executeInteraction, shoot, reloadWeapon и selectHandSlot. Проверки возможности игры общие; команды отпускания разрешены даже после открытия меню. Адаптер не реализует повторно combat, inventory или pathfinding.

Прежнее непрерывное следование удерживаемому указателю остаётся в существующем navigation update: оно обновляет цель без поиска пути на каждом событии мыши. Путь после отпускания и одноразовый клик проходят через MOVE. Существующие map/camera, UI drag и modal capture слушатели сохраняют свои области ответственности; это не два параллельных игровых input adapter.

`src/input/settings.js` добавляет выбор режима и CSS для интерфейса. Режим и незавершённые команды не сериализуются в gameplay save. Сетевые слои и multiplayer не добавлены.

## Разрешённые конфликты

1. ЛКМ оставлен движению, объектам и выбору врага; FIRE использует ПКМ. Пока активен один мировой жест, другой не создаёт конкурирующую команду. Можно стрелять при уже выполняющемся click-to-move.
2. Выбранная цель сохраняет прежний приоритет над курсором. Для свободной стрельбы используйте прежнее снятие выбора цели.
3. Взаимодействие поглощает свой жест и совместимый click: открывшееся окно не закрывается тем же кликом. Клик снаружи окна закрывает его без движения под ним.
4. Объект разрешается повторно по kind + id при отпускании: движущийся дрон не использует устаревшие координаты. Турели используют тот же INTERACT.
5. На PC протягивание начатого на объекте клика отменяет его, не превращая в неожиданное движение. Mobile-протягивание сохранено.
6. При отпускании ПКМ в комбинации кнопок учитывается buttons в pointermove. Pointer cancel, потеря захвата, blur, скрытие страницы, меню, переход и смена режима останавливают ввод.
7. Удалены прежние дублирующие обработчики R, C, 5 и Esc; совместимый mouse click после touch не повторяет мировую команду и не переключает AUTO.

## Сохранения и границы

Формат gameplay save, saveVersion и пять слотов сохранены. В метаданных выпуска указан 0.23.1; whitelist чтения дополнен только этой версией, прежние версии сохранены. Это не миграция игровых данных. Перенос между адресами по-прежнему требует экспорта/импорта; настройку Control Mode на другом адресе выбирают отдельно.

Баланс, оружие, AI, crafting, power, upgrades, поведение дрона и ресурсы не переработаны. Исходный CSS и изображения сохранены; дополнение интерфейса задаётся режимным CSS. Семь MP3, отсутствовавших в исходном проекте, не заменены.

## Ручная приёмка

На PC: загрузить прежний слот, пройти к точке/удержанием, открыть дрон, турель, сундуки, станки и генератор; пройти двери и люк; проверить ПКМ с целью и без неё, R, I, 1–5, M, C, Esc. Перетащить предмет между инвентарём и хранилищем. Во время огня открыть окно, переключить режим и свернуть браузер: огонь не должен продолжаться. Убедиться, что джойстики и Action исчезли, а HUD остался.

На телефоне: оба джойстика одновременно, Fire с выбранной целью, Action, перезарядка, сундуки, дрон, турель, станок, люк; pinch; портрет/альбом; редактор и сохранённые координаты кнопок. Проверить PC → MOBILE → PC и перезагрузку страницы. На гибридном устройстве проверить AUTO и ручное переопределение.

Автоматический стенд моделирует DOM и события, использует настоящий Canvas2D. Он не подтверждает нативный pointer capture, браузерную CSS-раскладку, Telegram WebView, Safari/iOS или FPS физического телефона. Эти пункты входят в ручную приёмку.
