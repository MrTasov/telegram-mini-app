# LAST BASE 0.27.0 — итоговый отчёт Этапов 6 и 7

Рабочая копия после остановки сохранилась. Финализация продолжена с текущего состояния без повторного рефакторинга и полного regression suite. Настоящий multiplayer не реализован. Сборка подготовлена для ручной проверки; отсутствие ухудшения производительности не подтверждено — ниже приведены обнаруженные замедления.

## Этап 6 — World Events / День X

`src/world/clock.js` отделяет игровые часы от UI; `src/world/events.js` вычисляет общий снимок событий и модификаторов. День X активен на каждом положительном дне, кратном 10, с 00:00 включительно до 06:00 исключительно. Перечисления отдельных дней нет. HP, damage, movement, attack frequency, специальные способности и spawn используют существующие величины усиления. Новые X-типы врагов не создаются. Повторное START/load не накапливает множители; завершение снимает временное усиление с сохранением доли HP.

Изменение относительно принятой старой версии: раньше событие действовало весь десятый день; окно сокращено до шести часов по заданию. Множители и остальной баланс сохранены. Новые звуки, красный туман, weather и другие эффекты не добавлялись. Реестр допускает последующее подключение таких модификаторов.

Проверены границы 9→10, 19→20, 29→30, Day 100, 00:00/05:59/06:00, load до/во время/после, повторные debug START/STOP. Старые контрольные saves не переписаны. Для дифференциального сравнения старого баланса время Day X в обеих исполняемых версиях приводится к 03:00 через `qa/event-test-contract.cjs`; реальные старые saves на 23:00 отдельно проверяют снятие усиления.

## Этап 7 — co-op readiness

Добавлены стабильные внутренние ID игрока и врагов, представление локального actor и общий исполнитель `GameSimulation.execute({actorId,type,payload})`. PC/Touch передают MOVE/AIM/FIRE/INTERACT/RELOAD/SELECT_SLOT/SNEAK в общий слой. Второй игрок не создаётся; неизвестный actor отклоняется.

Цель дрона, маркеры врагов и события убийства используют instance ID вместо индекса массива. Убраны выявленные изменения HP/ammo/UID из чтения карточек и HUD; игровые изменения выполняются на границах simulation/transactions. Время и события принадлежат миру, а локальная сцена не выдаётся за общий world state.

Миграция saveVersion 1→2 добавляет `identity027`, сохраняя пять слотов и старые adapters. Старые saves поддерживаются; новые saves формата 2 не предназначены для загрузки старыми сборками. Последняя защита отклоняет подложенные identity-поля повреждённого save до изменения мира; четыре дополнительных негативных теста прошли.

Подробный аудит по системам, включая фактические оставшиеся глобальные зависимости: [Multiplayer Readiness Report](MULTIPLAYER_READINESS_RU.md), разделы READY NOW / NEEDS NETWORKING STAGE / KNOWN LIMITATIONS.

## Performance comparison

Сравнение 0.26.0 → 0.27.0 выполнено последовательно в одной среде Node/native Canvas CPU: 60 прогревочных и 180 измеряемых кадров на сцену, viewport 1280×800, DPR 1. MOBILE/PC здесь обозначают режим управления, а не физическое устройство. Общая загрузка хоста и выбросы могут влиять на результат; считать ими доказанным отсутствие регрессии нельзя.

## Сборка и ручная проверка

Архив содержит готовые index.html, js, assets, исходники, инструменты сборки, tests, baseline и результаты. `npm ci`, `npm run check`, `npm test` — команды воспроизведения; сборка уже выполнена. Размещать на статическом HTTP(S)-хостинге с сохранением относительных путей, не открывать HTML внутри ZIP. Assets/locales/styles побайтово сравниваются с принятой 0.25.3 при упаковке. ZIP проверяется по CRC, уникальности путей и SHA-256 всех файлов; результаты находятся рядом в packaging-verification.json, внутри — release_manifest.json.

Для debug открыть `dev.html` на том же тестовом хостинге, затем выбрать игру. Панель предоставляет START X EVENT, STOP X EVENT, возврат CALENDAR и переходы 9 23:59 / 10 05:59. Используется тот же WorldEvents. Developer-launch заранее копирует localStorage в память: записи тестовой сессии не изменяют обычные saves. При невозможности изоляции запуск отклоняется. Обычный `index.html` не подключает debug; для публичной публикации исключить `dev.html` и каталог `dev/`.

После проверки вернуть обычный `index.html`. Вручную проверить PC и телефон, загрузку пяти слотов, Main Menu/EN-RU, переход 05:59→06:00, взаимодействия, дрона/турели и плавность в сценах из таблицы. Сборка остаётся single-player: один actor, старые локальные runtime/camera/scene зависимости подробно перечислены в отдельном отчёте. Нового gameplay/content и сетевого слоя нет. Работа остановлена для ручной проверки.
