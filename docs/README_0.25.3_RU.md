## GitHub-ready

Распакуйте архив и загрузите его содержимое в репозиторий. Для сайта нужны вместе `index.html`, `js/`, `styles/`, `assets/`. Готовая сборка уже включена: Node.js на GitHub Pages и телефоне не нужен. Для полного проекта сохраните также `locales/`, `src/`, `tools/`, `qa/`, `docs/`, `package.json` и `package-lock.json`.

Сохраните прежний адрес сайта: localStorage привязан к адресу. Для переноса на другой адрес используйте существующий экспорт/импорт saves. После обновления полностью перезагрузите страницу.

Локальный запуск:

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Выбор языка и режима управления хранится отдельно от игрового прогресса.

## Что изменилось

- Карта: команда Go here / Идти сюда запускает маршрут из открытой карты; защищающие игру проверки остальных окон, смерти и перехода сохранены.
- Общая шкала добычи/обыска следует экранной позиции персонажа, включая края мира, масштаб и изменение размера экрана.
- Переведены HUD, меню, Settings, предметы, рецепты, взаимодействия, сообщения, карты, журнал и Canvas-подписи.
- Живое EN/RU не пересоздаёт player, игру или кнопки. Международные модели оружия и калибры остаются независимыми от языка.

## Файлы

- `locales/` — парные каталоги и контекст старых подписей.
- `src/manifest.json` — порядок 64 секций исходников.
- `js/game.js`, `js/game.js.map` — готовая сборка и source map.
- `assets/manifest.json` — каталог 99 неизменённых изображений и metadata атласов.
- `docs/LOCALIZATION_RU.md` — архитектура переводов, новые ключи, добавление языка.
- `docs/STAGE5_REPORT_RU.md` — итоговый отчёт и результаты тестов/замеров.
- `docs/STAGE4_FIXES_RU.md` — причины и проверки двух исправлений.
- `docs/ASSETS_RU.md` — структура ресурсов, ручная замена, атласы и кэш.
- `docs/CONTROLS_RU.md` — принятые PC/Mobile controls.
- `qa/results/summary.json` — актуальный полный suite.
- `qa/stage4-fixed/` — эталон 0.24.1 после исправлений, до локализации; остальные папки эталонов исторические.

Обычный asset можно заменить файлом с тем же именем/форматом/путём. Для изменённого атласа обновите metadata и пересоберите. Семь необязательных MP3 отсутствовали в исходной версии и остаются необязательными; новые звуки не добавлялись.

## Разработка и проверки

```sh
npm ci
npm run build
npm run check
npm test
npm run bench
```

Нужен Node.js 20+. Canvas-зависимость используется только тестами; build не требует сторонних пакетов. Редактируйте `src/`, `locales/*.json`, `assets/manifest.json`, затем выполняйте сборку. Не редактируйте сгенерированный bundle вручную.

Замеры стенда не являются FPS телефона. Версия подготовлена для ручной проверки PC/телефона; следующий этап не начат.
