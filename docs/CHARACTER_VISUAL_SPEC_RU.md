# Визуальный стандарт LAST BASE 0.29.0

База: 0.28.0, проверенный архив; до изменений изучены core/rendering, combat/monsters, player/controls, fortress draw wrappers, base/rooms rest, construction tool jobs, assets/resources и Asset Manifest.

- Перспектива: высокая камера сверху, около 75–80°, ортографическая, единая для героя и заражённых; никакой изометрической смены карты.
- Основное направление исходных кадров: вниз (+Y). Действующий renderer вращает весь составной персонаж по aim-вектору, зомби — по существующему runtime angle. Направление пуль и collision не меняется.
- Свет: мягкий верхний/передний свет с небольшим смещением влево в исходной позе; без запечённой длинной тени. Тени остаются в игровом renderer.
- Герой: взрослый выживший, короткие тёмные волосы, оливковая куртка, тёмные брюки, потёртые ботинки, естественные пропорции, без карикатурной головы. Сдержанная realistic survival texture.
- Масштаб: герой близок к исходному игровому footprint; новая детализация не увеличивает hitbox. Зомби и тела умерших получают общий визуальный множитель 0.88; gameplay radius/specs неизменны.
- Frames: 8 пустые руки, 8 огнестрельное оружие, 8 перенос инструмента и 8 удар инструментом, 4 сон. Для каждого из пяти типов зомби — 8 ходьба + 4 атака.
- Anchors: отдельные root/body pivot, две кисти, grip и support grip предмета; данные кадров в manifest/visual configuration. Спрайты предметов отдельные, крепление вычисляется из тех же pose anchors, что и кисти. Модель оружия не определяет body atlas.
- Сон: четыре спокойных положения дыхания, голова у подушки существующей кровати. Rest owner и его HP/timing сохраняются.
- Память: внешние атласы, общий GameAssets cache, одно декодирование на resource ID, без отдельных Image на персонажа/кадр. Размеры рабочих атласов подбираются по реальному игровому масштабу.

Это стандарт до генерации; фактические размеры, anchors и итог кадров фиксируются после просмотра и интеграции.
