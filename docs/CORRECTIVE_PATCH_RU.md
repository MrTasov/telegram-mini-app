# LAST BASE 0.27.1 — Gameplay / UX corrective patch

Основа — сохранённая рабочая версия 0.27.0 после Этапов 6–7. Патч не создаёт новую игру, второй игровой цикл или сетевой слой. Архитектура owners, commands, WorldClock/WorldEvents и versioned saves сохранена.

## Причины и исправления

| Система | Причина | Исправление |
|---|---|---|
| UI / пауза | `menuOpen` одновременно означал захват ввода окном и паузу части simulation. Часы/дрон могли работать, а враги/турели — стоять. | `GameFlow.paused` отделяет остановку мира от открытого UI. Inventory, Settings, карты и панели объектов продолжают simulation. Main Menu до старта, смерть, скрытая вкладка и явные причины паузы остаются отдельными состояниями. `menuOpen` по-прежнему защищает от кликов сквозь окно. |
| Loot | Общая операция передачи обновляла список, но не закрывала опустевший контейнер. | После переноса выбранной стопки либо всех предметов общее loot-окно закрывается только при отсутствии оставшихся предметов. Частичный перенос при нехватке места оставляет окно открытым. Используется один обработчик для рюкзака и груза дрона, машины/дома/мебельных loot-контейнеров. |
| Автоматические проходы | Дверь ванной попадала в cached solid geometry; старое игнорирование bunker doors не охватывало её и не проверяло доступность питания. | `GamePassages` задаёт допустимость прохода при планировании отдельно от фактического collider/визуального состояния. Планирование не открывает двери. Ванная и powered bunker doors открываются прежними proximity-механизмами при подходе. Неподключённая закрытая дверь не считается автоматически доступной; ручное открытие сохраняется. Ключ кэша пути включает доступность проходов. Новые разрешения для ванной/главных ворот относятся к игроку: политика движения дрона и его snapshot питания сохраняются. |
| Главные ворота | В данной версии actuator ворот был ручным и двоичным; существующей автоматической анимации у него нет. | Общий passage layer разрешает маршрут через главные ворота и вызывает прежнее открытие, когда персонаж приблизился и следующий участок маршрута пересекает проём. Дальний клик сам по себе ворота не открывает. Телепортации и нового визуального эффекта нет. |
| Движение и действия | Выбор зомби явно отменял обычную navigation, а открытие overlay вызывало общий `stopControls`; некоторые object UI повторяли остановку. | `GameMovement` описывает совместимость действий с движением. Выбор цели, Reload, quick slot, Inventory/Settings/Map и панели объектов сохраняют движение. UI освобождает огонь/прицел, но сохраняет маршрут и удерживаемый левый joystick; отпускание pointer обрабатывается и над overlay. Mining/chopping/search/channeling и переходы, требующие остановки, сохраняют stationary-поведение. |
| Лестницы | Генератор создавал по четыре лестницы на сторону — всего 16. | Четыре лестницы: N (800,170), E (1390,600), S (1050,1030), W (210,600). Южная смещена вправо от ворот; остальные по центру сторон. Footpoints, анимация подъёма/спуска, механика повреждения опоры и wall walk сохранены. |
| Дрон / ремонт | HP не был явно отделён в UI от заряда; ремонт API был доступен только на станции, но кнопка находилась в панели дрона. | UI показывает «Прочность / Durability» и «Заряд / Battery». Полевой ремонт доступен рядом с развёрнутым дроном при прочности > 0. Станция ремонтирует пристыкованного дрона, включая прочность 0. Внутреннее `hp` и сохранения не переименованы. |

Обычные хранилища с двусторонним переносом и станции не являются одноразовыми loot-окнами: опустевшее постоянное хранилище остаётся доступным для помещения предметов. Автозакрытие относится к общему окну добычи `lootOverlay`.

## Намеренные gameplay / UI изменения

- Открытое окно больше не защищает игрока от мира: время идёт, враги атакуют, дрон/турели/производство и День X продолжаются. Начатая перезарядка тоже продолжается. Область карты открывается при движении даже под UI.
- Маршруты и удерживаемое движение сохраняются при совместимых действиях; UI не передаёт новые клики в мир. Начало stationary work останавливает движение.
- Главные ворота могут открыться при подходе по маршруту. Другие ручные или заблокированные проходы автоматически доступными не объявляются.
- Внешних лестниц теперь четыре вместо шестнадцати. Сами стены, их HP, уровни и ID не изменены.
- Полевой ремонт дрона теперь доступен без станции при прочности > 0. Полностью сломанный дрон ремонтируется на существующей станции.

Стоимость ремонта сохранена: **1 деталь на каждые 25 недостающих единиц прочности**, округление вверх; неповреждённый дрон ресурсы не расходует. Конфигурация: `src/drones/companion.js`, `ITEM.drone014.drone.repair = {material:'parts', durabilityPerUnit:25}`. Прочность и battery независимы: ремонт не добавляет заряд. При отсутствии деталей операция не изменяет прочность/ресурсы.

Восстановление сломанного дрона: подойти → забрать в рюкзак → принести в энергоблок → встать у свободной стороны площадки станции → «Поставить из рюкзака» → «Починить дрон». После ремонта разряженному дрону отдельно требуется зарядка. Сохраняются cargo, ammo, modules и прежний instance ID.

## Сохранения и неизменённые системы

Сохраняются пять localStorage slots, schema 2 / saveVersion 2, все поля существующих сохранений, EN/RU, Main Menu и PC/Mobile router. В whitelist release-версий добавлена 0.27.1; новая миграция не нужна. Assets и CSS не изменены. World Event definitions, характеристики оружия, множители Дня X и характеристики врагов не менялись. Старые контрольные fixtures не переписывались.

## Проверки

Полный существующий regression suite: **10 453 проверки, 0 ошибок**, 24 задания, около 452 секунд. В этот прогон включены 95 новых corrective-проверок.

После финального ограничения passage permissions для дрона выполнен целевой прогон на окончательном коде: **96 corrective-проверок, 392 проверки сборки/ресурсов, 996 differential-проверок и 58 state/save-проверок — без ошибок**. Добавленная проверка подтверждает, что drone path probes используют прежний snapshot питания и не считают закрытые ванную/главные ворота автоматически доступными для дрона. Эти результаты не складываются с полным suite: часть проверок повторяется. Точные результаты: `qa/results/summary.json`, `corrective.json`, `corrective-finalization.json`.

В полном suite прошли взаимодействия (831), PC/Mobile controls (64), assets (334), asset rendering (120), карта/шкала добычи (55), EN/RU (3473), localization rendering (74), EN controls/interactions (950), Main Menu (106), preferences/fullscreen (17), World Events (118), readiness (60), save/state и сравнения с историческими версиями. 75 исторических fixture-файлов Stage 0/1/2 прошли меню load→save→load; все пять slots проверены. Отдельно сохранён roundtrip полностью сломанного, перенесённого на станцию и отремонтированного дрона с пустой батареей.

Проверены powered bunker doors (все семь), ванная и главные ворота одним movement command без раннего открытия; отсутствие разрешения для unpowered closed doors; четыре лестницы и подход к каждой в PC/MOBILE; частичный/полный loot transfer; target/Reload/quick slot/UI на обычном и map route, удерживаемый touch joystick, stationary mining/chopping, продолжение атак врагов/турелей, полёта/зарядки дрона и перехода Дня X под UI. Проверка повторных open/close подтверждает отсутствие новых listeners/timers/loops.

Исторические проверки лестниц намеренно адаптируются в временной копии suite: одна лестница на сторону вместо четырёх, проверка подъёма/спуска по всем четырём оставленным лестницам. Исходные frozen tests/fixtures сохранены. Поэтому historical baseline даёт 417 проверок вместо 477: 60 повторений для двенадцати удалённых лестниц больше не применимы. Новые тесты дополнительно проверяют подход ко всем четырём лестницам в PC/MOBILE и разрушенную опору.

## Короткое сравнение производительности

0.27.0 → окончательный runtime 0.27.1, последовательные прогоны после тестов: 60 прогревочных и 180 измеряемых кадров на сцену, 1280×800, DPR 1, Node/native Canvas. Контроль 0.27.0 сохранён от первого прогона; после завершающей правки повторены только candidate-замеры. MOBILE/PC — режим ввода, не физические устройства.

## Ограничения и ручная приёмка

Автотесты выполняются в VM с моделируемым DOM и native Canvas2D, без физического телефона/Telegram WebView. Семь отсутствующих необязательных аудиофайлов — прежнее известное ограничение, без добавления временных звуков.

Проверить вручную на PC и телефоне: UI под атакой, движение + цель/Reload/quick slot, один клик через ванную/двери/ворота, пустой и частично разобранный loot, четыре лестницы, ремонт дрона при 0 и ненулевой прочности, батарею отдельно, EN/RU и загрузку своих slots.

Распаковать архив полностью и обновить существующий сайт, сохранив origin и структуру папок. Готовый runtime уже собран; для разработки: `npm ci`, `npm run build`, `npm run check`, `npm test`. `dev.html` — прежний изолированный инструмент Дня X; исключить его и `dev/` из обычной публичной публикации. Работа заканчивается этим патчем; networking и новые крупные системы не добавлены.
