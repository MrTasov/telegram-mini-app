# Stage C1: восстановление и Power bootstrap

Основа — принятая 0.32.1 Stage A/B Corrective. C1 не включает окончательный Chapter 1, повреждённый обычный New Game, Building/Placement или Level 2. Исходный Master Implementation Roadmap сохранён без изменений.

## Владельцы и определения

| Область | Владелец / контракт |
| --- | --- |
| Стены и ворота поверхности | `V015Base.sections`; прежние ID, положение, HP и уровни |
| Двери бункера, домов и санузла | Прежние объекты `V018Build.doorRecords`; сохранение `building018` |
| Типы повреждений / ремонта | Отдельные определения `wall_section`, `perimeter_gate`, `bunker_sliding_door`, `house_door`, `bathroom_door`; прежние значения Lv.1–5 |
| Оплаченная ремонтная смесь | Единственный `V018Build.credit`, сохраняется; отдельного инвентаря ремонта нет |
| Работа ремонта | Временный job с actorId; UI не владеет работой; после загрузки требуется снова начать ремонт, HP и credit сохранены |
| Tank / Generator / Battery | Прежние `V09Power` / `V010Energy`; Stage B instance IDs и transform используются для доступа |
| Критическая геометрия | Core, лестницы, опоры/оболочка бункера и фиксированные станции защищены; не добавляются в список разрушаемых объектов |
| Повторные команды | `recovery033.commands`: revision, до 128 receipts; повтор после загрузки не тратит ресурс снова |

`GameRecovery.classify/status` читает существующие объекты. Не создаётся второй HP, дубль fuel/charge или сериализованная копия geometry. Восстановимы существующие секции и двери. Добавление разрушаемых новых станций/обороны относится к последующим этапам.

## Команды

UI передаёт `actorId`, `instanceId`, `action`, `payload`, `expectedRevision`, `requestId` через тот же `EquipmentCommands` gate, который используется Stage B. Доступ проверяется при commit. Неизвестные/удалённые actors не перенаправляются к локальному рюкзаку. Локальный adapter поддерживает существующего игрока; сетевого транспорта нет.

Операции: repair, upgrade, stopRepair, manualOpen, refuel, generator, battery. Fuel принимается целыми единицами; неполный остаток вместимости не сжигает целую канистру. Генератор запускается физической панелью энергоблока без электричества; существующий remote также сохранён. Заправка требует подхода к Tank. Закрытые двери сохраняют прежний ручной interaction range.

Ремонт списывает один бетон при пополнении credit и лечит тот же объект. Повтор start не создаёт второй job. Уход, потеря инструмента/actor или занятый пролом не расходуют новый материал. Меню инвентаря не останавливает world job; реальная пауза/скрытое приложение останавливает tick. Изменение collision при разрушении/восстановлении использует прежний geometry revision.

## Неактивный preset

`GameNewGame.create()` возвращает прежний чистый шаблон. Только явный `GameNewGame.previewBootstrap()` создаёт отдельную копию с `CampaignBootstrap` draft. Фабрика не принимает входной save и не вызывается из restore/migration. Она не пишет слот сама.

Проверочный draft: одна разрушенная наружная секция, дверь с недостающими 2000 HP, Generator off, Tank empty, Battery zero, закрытые двери, доступная через ручное открытие мастерская. Стартовый молот, 1 fuel и 24 stone позволяют изготовить 12 concrete и восстановить оба объекта. Минимальные необходимые линии включены; все фиксированные экземпляры остаются на местах. Farm/Animals остаются в паузе.

Эти количества служат **только проверкой отсутствия цикла зависимости**. Это не утверждённый баланс C2. Campaign definitions, objectives, rewards и unlocks не изменены.
