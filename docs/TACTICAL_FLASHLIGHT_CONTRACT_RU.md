# Tactical Flashlight: предмет, модуль и свет

`flashlight` остаётся стабильным type ID ранее существовавшего предмета. Отображаемое имя — «Тактический фонарь» / “Tactical Flashlight”. Craft: существующий верстак, 4 iron + 2 copper + 1 parts, 12 секунд. Для установки подходит прежний Tactical Helmet или новое головное крепление без характеристик (2 iron + 1 parts, 8 секунд).

Физическая принадлежность: equipment.head → attachments.flashlight. У родителя и дочернего предмета собственные UID. Представление attachment использует typeId и transform относительно parentId/slot. Это переносимый предмет, поэтому новый фиксированный world instance не создаётся. В обычном инвентаре/на складе модуль не даёт свет. Снятие головного снаряжения переносит весь комплект; снятие самого модуля требует места в рюкзаке.

`GameHeadModules` использует Stage B EquipmentCommands: actor, parent instance, request ID, revision, bounded receipts. UI только инициирует действие. Save хранит сам предмет в одном контейнере, без дублирующего списка установленного оборудования. Дубликаты module UID, неправильный slot/type/qty отклоняются до изменения мира.

Миграция старого save переносит один прежний фонарь из quick/bag в голову; недостающий ранее доступный фонарь выдаётся как compatibility module. Если голова пуста, создаётся statless mount без HP, armor, accuracy или speed бонусов. Другие предметы/шлем и их улучшения сохраняются. Повторная миграция не создаёт второй модуль. Обычный New Game бесплатного модуля не получает.

F и кнопка 🔦 включают установленный модуль независимо от выбранного инструмента. При оружии emitter совпадает с его muzzle pose; при ручном фонаре — с линзой существующего artwork; при свободных руках — с невидимым head socket. Отрезок от игрока до emitter проверяется на препятствия, чтобы источник не оказался внутри стены. Никаких новых sprites/animations/визуального helmet не добавлено.

Основной луч сохраняет физические blockers. Контакт центрального луча даёт небольшой highlight и слабое переднее полукруглое рассеяние, отсечённое соседними blockers. Один контакт, 13 дополнительных коротких лучей, существующий mask и sprite cache; GI и отдельного framebuffer для bounce нет. Свет через двери — локальный градиент в соседнем тёмном помещении, ограниченный проёмом и фактическим opening; закрытая дверь не пропускает свет. Разрушенная дверь считается открытым проёмом. Шлем и установленный модуль не рисуются на sprite персонажа. Заряд и durability фонаря не симулируются. Основной мягкий конус использует одну кэшированную текстуру 256×256 и одно наложение за кадр; это заменяет прежние 16 наложений без увеличения числа текстур.
