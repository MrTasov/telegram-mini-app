# LAST BASE 0.22.0 — результат Этапа 2

Выполнен только этап «Упорядочить состояние и сохранения» поверх принятой вами версии 0.21.0. Этап 3 не начат. Контрольные данные Stage 0 и принятый исходный комплект Stage 1 сохранены.

## Что изменено

- **GameState:** единый каталог 15 владельцев состояния с живыми ссылками на текущие объекты. Служебные флаги, активный слот, имя, проверенная копия и таймер сохранения собраны в `GameState.session`.
- **GameSave:** явный реестр 56 save-адаптеров вместо последовательного переопределения глобальных capture/decode/restore. Прежний порядок операций проверяется при запуске. Семь существующих подсистем V010 зарегистрированы через тот же центр; дублирование и поздняя регистрация запрещены.
- **Формат:** добавлено `saveVersion: 1` с миграцией старых saves без этого поля. Сохранены ключи localStorage, пять слотов, резервные копии, существующие схемы и IDs.
- **Восстановление:** данные проверяются до применения и загружаются из отдельной копии. Уже проверенный неизменённый объект не проходит тяжёлую валидацию повторно; любое изменение снова проверяется. Автосохранение приостановлено на всё время восстановления.
- **Проверки:** добавлены тесты владельцев, повреждённых/будущих saves, слотов, изоляции данных и сравнение полного save payload с реальной принятой 0.21.0.

Игровые характеристики, баланс, управление, AI, расположение объектов, CSS и все 99 изображений сохранены. В проекте 56 исходных JS-секций; крупнейший файл исходников — около 47 КБ. Готовый runtime остаётся одним classic script для GitHub Pages.

## Отдельное намеренное исправление

Обнаружена и воспроизведена на неизменённой 0.21.0 старая ошибка создания новой игры: ранний шаблон не содержал всех электрических контуров. Валидация завершалась ошибкой, которую UI представлял как проблему хранилища.

Теперь полный стартовый шаблон фиксируется после создания всех систем и до первой загрузки слота. Новая игра работает и не наследует повреждения стен, груз/улучшения дрона, ферму или День X из предыдущего слота. Начальный баланс сохранён. Это единственное исправление существующего игрового сценария сверх организационных изменений и защиты загрузки данных.

Поэтому эти прогоны не позволяют уверенно отделить постоянное изменение производительности от нагрузки общего вычислительного узла. У итоговой версии уменьшенный масштаб был медленнее ближайшего контроля: примерно **+9,4% по медиане, +31,9% по p95**. Эту сцену особенно стоит проверить на телефоне. Утверждения об ускорении игры или неизменном FPS телефона по этим данным не делаются.

Первый диагностический прогон выявил лишнюю повторную валидацию при decode → restore. Она устранена с сохранением проверки изменённых данных. Итоговые показатели сохранения/загрузки находятся в диапазоне контрольных запусков или рядом с ним:
