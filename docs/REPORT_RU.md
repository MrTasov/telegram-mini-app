# LAST BASE 0.21.0 — результат Stage 1

Исправлены interaction-баги версии 0.20.0, затем выполнен этап «Безопасно разделить код». Этап 2 не начат. Исходный комплект Stage 0 сохранён без изменений.

## Исправленная причина

Окна объектов открывались на `pointerdown`/`pointerup`, а завершающий `click` того же жеста закрывал их как нажатие снаружи. Это воспроизведено у станка, печи, хранилищ, турели и других объектов. При подходе издалека окно открывалось позже клика, поэтому ошибка выглядела непостоянной.

Общий обработчик теперь различает открывающий и следующий закрывающий жест. Не нужны задержки или отдельные обходные решения для каждого окна. Закрытие снаружи по-прежнему не нажимает на предметы под карточкой.

У дрона дополнительно исправлены выбор корпуса и приоритет над станцией: область нажатия соответствует его изображению, повороту и покачиванию. На отпускании используется актуальная позиция выбранного объекта. Дистанции доступа, коллизии и поведение дрона сохранены.

## Что сделано в Stage 1

- Игровой JS разделён на **51 исходный файл** по областям игры; крупнейший — около **47 КБ**.
- HTML и статический CSS отделены. Все 99 изображений сохранены побайтно и по прежним путям.
- Добавлена простая сборка `node tools/build.cjs`, карта исходников для отладки и проверка актуальности сборки.
- Для браузера файлы собираются в один обычный скрипт: сохраняются порядок, hoisting, общая область видимости и существующие расширения функций.
- Форматы saves, ID и ключи хранилища не изменены. Версия 0.21.0 добавлена в существующий список разрешённых версий.
- Добавлена запись об обновлении. Старый генератор HTML из 0.19.1 заменён единственной рабочей цепочкой `src/manifest.json` → `js/game.js`.

Это разделение исходников, а не переработка систем или владения состоянием. React, Vite, новые игровые зависимости и механики не добавлялись.

## Ограничения и следующая проверка

В этом окружении не было доступного нативного браузера/Telegram WebView и физического телефона. События проверены на модели DOM с исполнением реального игрового кода и нативным Canvas2D. Нативные pointer events, CSS-раскладку и мобильный GPU нужно проверить вручную на готовой версии. Ошибок консоли в автоматических прогонах нет.

В исходном Stage 0 отсутствовали семь MP3: `gunshot`, `zombie`, `hit`, `player_hit`, `footsteps`, `chicken`, `cow`. Новых пропавших путей нет; звуковые файлы не заменялись и их фактическое воспроизведение не заявляется проверенным.

## Как использовать комплект

Распакуйте `LAST_BASE_0.21.0_Stage_1_GitHub.zip` и загрузите содержимое в репозиторий. Для запуска вместе нужны `index.html`, `js/`, `styles/`, `assets/`. Полный архив также содержит исходники, инструкции и тесты. ZIP не нужно загружать вместо распакованных файлов; самый крупный отдельный файл — около 2 МиБ.

Основной результат тестов: `qa/results/summary.json`. Подробности, контрольные saves и измерения находятся в `qa/`; точный diff interaction-исправлений и руководство — в `docs/`.

Работа остановлена на завершённом Stage 1 для вашей ручной проверки компьютера и телефона. Следующий этап требует отдельной команды.
