# LAST BASE 0.25.0 — итог Этапа 5

**Этап 5 завершён. Полный regression suite: 10,020 / 10,020, ошибок 0.** Этап 6 не начат. Версия подготовлена для ручной проверки PC и телефона.

## Исправления ручной проверки Этапа 4

**Карта.** Прежняя общая защита ввода блокировала MOVE, пока была открыта сама карта. Кнопка «Идти сюда» теперь отправляет явную команду маршрута из верхнего окна карты через существующий GameActions. Проверки смерти, скрытой вкладки, перехода и постороннего окна поверх карты сохранены. Выбор объекта не превращён в конкурирующее движение.

**Шкала добычи.** Общая полоса добычи/обыска использует worldToScreen(player.x, player.y) и пересчитывает положение после актуальной трансформации камеры. Она остаётся над персонажем у четырёх краёв мира, при масштабе и изменении ориентации. Длительности, количество ресурсов и условия действий не менялись.

Обе ошибки воспроизведены на 0.24.0. После исправлений отдельно прошли 5574 / 5574 проверки Этапа 4, включая 55 новых. Этот эталон 0.24.1 сохранён в `qa/stage4-fixed/`; только после его успешной проверки начат авторизованный Этап 5. В финальном выпуске те же 55 проверок повторены на RU и EN.

## Localization EN/RU

- 1561 парных ключей в `locales/en.json` и `locales/ru.json`: HUD, Settings, предметы, описания, рецепты, сообщения, дрон, строительство, карты, журнал и Canvas-подписи.
- Общий I18n.t(key, params), параметры, формы множественного числа, Intl-форматирование чисел/дат и сортировка по отображаемым именам.
- Для прежнего кода сохранён адаптер вывода по стабильным ключам. Канонические данные simulation и исторические поля saves не переименовываются. Новые тексты добавляются через осмысленные ключи.
- EN ↔ RU меняет существующие текстовые узлы и атрибуты. Кнопки, обработчики, пользовательский ввод и игровой прогресс сохраняются; нет второго player/game loop/input router.
- LAST BASE, модели оружия и калибры сохраняют международное написание. Прежнее визуальное «АК-74» нормализовано до AK-74; внутренние IDs прежние.
- Имена сохранений, меток и дрона не переводятся. Изменённые имена ящиков защищены; старый save format не отличает пользовательское имя, точно совпадающее со стандартным названием того же ящика.

Подробности и инструкции добавления языка: `docs/LOCALIZATION_RU.md`. Область изменений и diff: `docs/STAGE5_CHANGE_SCOPE_RU.md`, `docs/stage5-source.patch`.

## Производительность

Сравнение **0.24.1 → 0.25.0**, один стенд, MOBILE; кандидат на English. Пять сцен, 60 прогревочных и 180 измеряемых кадров на сцену, последовательный запуск версий. Включены update + draw и принудительное завершение растеризации Canvas.

| Сцена | p50, мс: до → после | Изменение p50 | p95, мс: до → после |
| --- | ---: | ---: | ---: |
| Поверхность, день | 27.60 → 27.41 | -0.69% | 31.27 → 31.38 |
| Ночь, день X | 60.23 → 59.89 | -0.56% | 68.64 → 66.21 |
| Бункер, питание и дрон | 43.88 → 42.69 | -2.72% | 48.42 → 46.70 |
| Открытый инвентарь | 36.11 → 35.73 | -1.07% | 43.74 → 39.30 |
| Поверхность, отдалённая камера | 36.14 → 36.42 | +0.79% | 41.30 → 42.31 |

Медианное время кадра изменилось в пределах −2,72%…+0,79%; устойчивого замедления на стенде не обнаружено. Эти значения **не являются FPS телефона** и зависят от нагрузки общего CPU.

Три чередующихся холодных запуска в отдельных процессах при 390×844:

| Показатель | 0.24.1 | 0.25.0 |
| --- | ---: | ---: |
| Медиана локального старта JS/DOM + начального декодирования | 455.8 мс | 434.4 мс |
| Начальные Canvas image requests | 2 | 2 |
| Оценка RGBA этих изображений | 7 176 192 байта | 7 176 192 байта |
| Уникальные URL Canvas + DOM при старте | 20 | 20 |
| Байты этих изображений | 1 858 069 | 1 858 069 |
| Готовый JS, без сжатия | 1,049,009 байт | 1,379,205 байт |
| JS, локальный gzip-эквивалент | 335,055 байт | 445,423 байт |

**Память не объявляется неизменной:** два каталога и слой локализации требуют дополнительного JS heap. В трёх отдельных парах запусков после принудительного V8 GC медиана удерживаемого прироста heap составила 7.56 → 9.69 MB, то есть **+2.13 MB**. До GC разница прироста heap — около 3,05 MB; это включает временные выделения. Память исходных изображений не выросла. RSS и heap относятся к стенду с моделью DOM; память браузера/GPU и физического телефона здесь не измерялась.

Используются компактный индекс фраз, кэш строк до 1024 записей, кэш Intl до 64 записей и WeakMap-привязки. Локализация не добавляет обработку всего DOM на каждом кадре. Оба каталога встроены в bundle, поэтому нет дополнительного запроса при переключении языка. Размер JS увеличился на 330 196 байт без сжатия / 110 368 байт gzip-эквивалента; это следует учитывать при оценке реальной мобильной сети.

Полные исходные замеры: `qa/results/stage5-performance-comparison.json`, `stage5-performance-before.json`, `stage5-performance-after.json`, `stage5-loading-*.json`, `stage5-memory-comparison.json`. Воспроизведение: `node qa/compare-performance.cjs`; измерение удерживаемого heap — `node --expose-gc qa/localization-memory.cjs <index.html> <report.json>`.
