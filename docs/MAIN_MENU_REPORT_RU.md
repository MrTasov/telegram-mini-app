# LAST BASE 0.25.3 — исправления главного меню

Отдельный патч поверх 0.25.2. Этап 5 сохранён; Этап 6 не начат.

## Изменения по ручной проверке

1. **Настройки из меню снова доступны.** Причина: фиксированный контейнер игры создавал отдельный CSS stacking context. Окно Settings открывалось внутри него и оставалось за главным меню, несмотря на собственный высокий z-index. Теперь меню и существующие окна Settings/редактора управления находятся в одном контейнере; модальные окна выводятся выше меню. Новое окно настроек не создавалось: обе кнопки открывают один и тот же элемент `settingsOverlay` с теми же обработчиками и ключами настроек.
2. **Общие настройки до и после запуска.** English/Русский, Control Mode, звук и fullscreen доступны из обоих экранов. Редактор расположения управления теперь также доступен до начала игры. Настройки сохраняются прежним способом. Закрытие окна до выбора save оставляет главное меню активным и мир неподвижным. Сохранение прогресса и другие команды текущей игровой сессии показываются после её запуска.
3. **Полный экран на телефоне уже в меню.** В поддерживающем Telegram на Android/iOS запрос отправляется сразу. В поддерживающем браузере — при первом касании меню, в рамках того же пользовательского действия. Это не отменяет выбранную кнопку. Exit не запрашивает браузерный fullscreen. При отсутствии API, запрете или отклонённом Promise интерфейс продолжает работать. Повторить запрос можно через общую кнопку полноэкранного режима в Settings. Используются реальные touch capabilities/платформа и тип ввода, а не только ширина экрана. На PC fullscreen остаётся явным выбором через Settings.
4. **Пять основных кнопок компактнее.** Их видимая площадь уменьшена примерно вдвое; текст не масштабируется в два раза до нечитаемого размера. Для телефона область касания расширена вертикально без увеличения видимой кнопки. Размеры элементов выбора save и Settings не уменьшались. Исходные PNG, фильтры фона, дымка и положение блока относительно нижнего края сохранены.

Fullscreen зависит от устройства и приложения. Для браузерного requestFullscreen требуется действие пользователя; гарантировать удаление системных панелей в любом браузере нельзя. Это учитывает [Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen) и [Telegram Mini Apps API](https://core.telegram.org/bots/webapps). Старые Telegram-клиенты проверяются по доступности API/версии. Переход в игру больше не создаёт отдельный отложенный запрос fullscreen; незавершённые браузерные запросы не дублируются.

## Регулировка оформления

Все параметры остаются в `styles/main-menu.css`. Параметры фона не менялись.

| Параметр основных кнопок | PC landscape | Mobile portrait |
|---|---:|---:|
| `--menu-ui-width` | до 640px | 42% ширины экрана |
| `--menu-home-button-height` | 34px | 32px |
| `--menu-home-font-size` | 11px | 11px |
| `--menu-ui-x` | 50% | 65% |
| `--menu-ui-bottom` | 5% | 4% |

Для короткого portrait и небольшого landscape сохранены отдельные адаптивные правила. У основных кнопок на coarse pointer прозрачная область касания выступает на 6px сверху и снизу; в обычном portrait получается 44px по высоте. Параметр `--menu-button-height` относится к остальным кнопкам меню и оставлен прежним.
