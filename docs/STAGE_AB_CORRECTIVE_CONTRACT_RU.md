# Контракты corrective patch 0.32.1

Основа — неизменённый поставленный архив 0.32.0 Stage B. Это исправление
Stage A/B после ручной проверки, не новый этап Roadmap. Приёмка ожидается повторно.

## Геометрия и сохранения

Layout R3 сохраняет оболочку Level 1, лестницы и визуальный Core. Семантические
IDs `workshop` и `room6` остаются прежними: первая комната смещена на −1000 по Y,
вторая на +1000. Порядок записей дверей сохранён для совместимости.

SaveFormat 7 → 8 сначала проверяет сохранённые instance transforms относительно
R2, затем переносит их в R3. Поддельный transform отклоняется до изменения мира.
При переходе 6 → 7 недостающие equipment records сначала создаются в исходной
планировке сохранения. Это предотвращает двойной перенос при цепочке 6 → 7 → 8.
Игрок, дрон, guard point, map goal/markers и служебная позиция игрока переезжают
вместе с комнатой; устаревший вычисленный путь дрона сбрасывается.
Повторный decode/load R3 ничего не сдвигает.

Очереди, ready output, refunds, содержимое хранилищ, item identity, upgrade slots,
энергия и campaign/equipment command receipts остаются у прежних владельцев.
Сельское хозяйство остаётся сохранённым и приостановленным. SaveFormat 8 не
предназначен для открытия старыми сборками.

`GameEquipment` по-прежнему владеет типом, экземпляром, transform и owner refs.
`GameFootprints.body(id)` выдаёт единственный физический прямоугольник из этого
transform и метаданных рисунка; его используют общая геометрия столкновений,
маршруты и препятствия света. Он доступен до загрузки изображения. Draw bounds
и pick bounds могут быть шире: PNG padding и нарисованная тень пола не создают
препятствий. Dock pad доступен для прохода, физическим телом остаётся колонна.
Редактор, перемещение оборудования и placement API не добавлены.

## Campaign и UI

Campaign schema 1, contentRevision 3. К прежним семи демонстрационным целям
добавлены четыре необязательные: медь после активации, медикаменты на складе,
работающий дрон и освещение мастерской. Три обязательные цели, две ранее
определённые главы, переходы и награды не изменены. Это не окончательный Chapter 1.
Завершённая глава при миграции не открывается заново, новые необязательные цели
в ней остаются неактивными. Команды главы сохраняют проверку actor/target/request,
ревизии, близости и питания Core.

HUD preference `objectives` — настройка устройства, не gameplay save и не условие
выдачи прогресса. UI показывает короткое подтверждение ✓ без изменения размеров
tracker. Раскрытые описания и выбранная глава являются временным состоянием UI.
Core регистрирует только работающие секции Base/Chapters. Future availability
получается от владельца соответствующей системы; UI не назначает unlocks.

## Аудио и свет

Обычный звук принадлежит scene/floor. При смене зоны старые голоса и loops
останавливаются; близость координат в разных зонах не даёт слышимости. Оборудование
использует актуальные координаты экземпляров. Числовой floor/level — идентификатор
этажа; прежний boolean level сохраняет смысл высоты поверхности.

Исключение допускается только при активном Day X, с явным `dayXLeak`, из surface
floor 0 в bunker и для ограниченного списка крупных событий. Усиление не больше
0.065 до остальных коэффициентов, с фильтром 420 Hz и затуханием по расстоянию
до люка. Обычные generator/machine/rotor/water через перекрытие не проходят.
Новый этаж не создаётся. Day X WAV и игровая логика события сохранены.

Дрон использует непрерывные координаты и проекцию силуэтов физических тел в
один буфер: сторона 128–512 в зависимости от экранного размера света, максимум
1 MiB. При zoom 0.65 это 256 × 256, около 1.4 экранного пикселя на texel;
билинейная фильтрация сохраняет плавное движение. Все тени объединены в одну
операцию заливки. Список ближайших препятствий кэшируется по ячейке,
ревизии геометрии и фактическому положению дверей. Квантизация положения света
и дополнительные raycasts для дрона не применяются. Неподвижный свет повторно
использует буфер. Прожекторы имеют дальность 640; их направления и цепи питания
сохранены. Яркость помещений и фонарей меняет визуализацию, не баланс энергии.
