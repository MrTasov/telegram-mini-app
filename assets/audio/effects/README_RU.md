# Звуковые эффекты

Эти 7 MP3 отсутствовали уже в принятой 0.23.1 и исходной Stage 0:
`gunshot.mp3`, `zombie.mp3`, `hit.mp3`, `player_hit.mp3`, `footsteps.mp3`, `chicken.mp3`, `cow.mp3`.

В `assets/manifest.json` они явно обозначены как optional. Игра не запрашивает отсутствующие файлы и не подменяет их синтетическим звуком. Остальная существующая аудиологика сохранена.

Чтобы впервые добавить эффект, положите MP3 с соответствующим именем сюда и выполните `npm run build`: сборка обновит признак наличия файла. Для последующей замены уже включённого эффекта по прежнему пути пересборка не нужна. После удаления включённого файла тоже выполните сборку.

WebAudio запускается после жеста пользователя. Запросы звуков проверяют HTTP-статус и используют `cache: no-cache` (браузер может переиспользовать кэш после проверки актуальности). Звуковые буферы декодируются один раз за сеанс. Громкость и игровой смысл эффектов не менялись.
