## Совместимость и границы архитектуры

SaveFormat **8**, Layout **R3**, campaign schema **1**, contentRevision **3**.
Сохранение 0.32.0 проходит миграцию 7 → 8; предыдущая цепочка миграций сохранена.
Для Stage A сначала создаются equipment records в исходной планировке, затем
выполняется перенос комнат. Повторная загрузка не сдвигает их ещё раз.

Семантические IDs и порядок сохранённых дверей сохранены. Проверены очереди,
готовая продукция, возвраты ресурсов, хранилища, upgrade slots, предметы,
питание и command receipts. Сельское хозяйство остаётся приостановленным с
сохранёнными данными. Завершённая глава не открывается заново ради новых целей.

Сохраняются Stage A Campaign/Chapter contracts и Stage B type → instance /
transform: общие definitions, постоянные instances, прежние владельцы ресурсов.
Проверки actor, target, request ID и expected revision остаются в domain-командах;
повтор команды после save/load не расходует ресурсы повторно. UI не получает
прав выдавать unlocks. Multiplayer-readiness остаётся подготовкой локальной
authority; сетевой транспорт и полноценный multiplayer не добавлены.

Внешняя геометрия Level 1, положение Core и лестниц, полная hit area лестницы и
исходные изображения сохранены. Игровая логика, расписание, баланс и WAV Day X
сохранены; изменена только явно запрошенная слышимость крупных наружных событий
из бункера. Освещение не повышает потребление оборудования.

## Что проверить вручную

Автоматизация использует моделируемые DOM и WebAudio, реальные PCM-файлы и
нативный Canvas2D. CSS-контракты и постоянство DOM проверены, но фактическая
компоновка в Telegram WebView, браузерная плавность, физический touch и
субъективное звучание остаются непроверенными на устройстве.

1. Открыть старое сохранение: мастерская наверху слева, кухня внизу;
   производство, склад, усиление и дрон сохранились. Пройти игроком и дроном
   в обе комнаты, к dock и по всему нижнему краю Core.
2. Переключить tracker и его настройку HUD; выполнить цель при скрытом HUD.
   Проверить ✓, обновление списка и отсутствие скачков соседних элементов.
3. В RU/EN переключать Base/Chapters, раскрывать описания, прокручивать длинный
   контент. Проверить portrait, landscape, PC и верхнюю панель Telegram.
   Header/tabs и внешний прямоугольник Core должны оставаться на месте.
4. Послушать новый микс в меню, мастерской, энергосекторе и на поверхности.
   Проверить затухание по расстоянию, отсутствие обычного оборудования сквозь
   этажи и отсутствие удара на рассвете. Отдельно оценить приглушённый Day X.
5. Сравнить lights off/on; двигать фонари игрока и дрона около Core/оборудования.
   Ночью проверить прожекторы вместе с обоими фонарями, в том числе при zoom.

Для проверки загрузить весь комплект `index.html`, `js/`, `styles/`, `assets/`
на прежний origin. ZIP содержит готовую сборку и исходники, без внешней папки
проекта и без node_modules. Старый экспорт полезен для отката: формат 8 не
читается прежними сборками. Итоговый inventory, SHA-256 каждого файла и список
изменений включены в `release_manifest.json` и `STAGE_AB_CORRECTIVE_CHANGESET.json`.

**На этом corrective patch работа остановлена для повторной ручной проверки.**
