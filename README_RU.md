# LAST BASE 0.29.0 — Full Audio Pass Recovery 1

Full Audio Pass восстановлен поверх предоставленного архива **LAST_BASE_0.29.0_HUD_Compact_1.zip**. Это новая восстановленная сборка, а не копия утраченного ZIP. Включены готовая игра, исходники, звуки, лицензии и тесты.

1. Распакуйте ZIP. Загрузите `index.html`, `js/`, `styles/`, `assets/` с сохранением структуры папок.
2. Сохраните прежний адрес сайта (origin) и данные браузера. Формат сохранений остаётся **3**; локальные слоты не требуют миграции.
3. Обновите страницу после загрузки всех файлов. Новый cache-tag — `0.29.0-audio-pass-recovery-1`.
4. Нажмите кнопку входа или коснитесь игрового экрана: браузер разрешает звук после действия пользователя. Проверьте существующий регулятор громкости.
5. Выполните ручную проверку из `AUDIO_PASS_RECOVERY_RU.md` на PC и телефоне.

Для готовой игры Node.js не требуется. Локальный запуск: `python -m http.server 8000`, затем `http://localhost:8000/`.

Для разработки: Node.js 20+, `npm ci`, `npm run build`, `npm run check`, `npm test`. Только audio: `npm run test:audio`. Замеры: `npm run bench:audio`, отдельно от тестов. Опциональная параллельность полного suite: `LAST_BASE_TEST_JOBS=3`.

Отчёт: `AUDIO_PASS_RECOVERY_RU.md`. Реестр покрытия: `AUDIO_AUDIT_RU.md`. Файлы и хеши: `AUDIO_PASS_RECOVERY_CHANGESET.json`. Все группы: `qa/results/summary.json`. Performance: `qa/results/audio-performance.json`. Источники, лицензии и обработка: `assets/audio/CREDITS.md`, `tools/audio-sources.json`, `tools/audio-preparation.json`.

Все WAV уже включены. Повторная загрузка исходных библиотек не нужна. При распространении сохраняйте атрибуцию: запись курицы — CC BY 3.0, обработанная запись коровы — CC BY-SA 3.0.

`character-preview.html` — прежний просмотр персонажа без изменения сохранений. `dev.html` — изолированный режим разработки. Материалы `qa/` и старые отчёты сохранены для воспроизводимости и относятся к указанным в них этапам. Следующее обновление не начато.
