# LAST BASE 0.29.0

Визуальный патч персонажа и зомби поверх стабильной 0.28.0.

1. Распакуйте архив. Загрузите `index.html`, `js/`, `styles/`, `assets/` с сохранением структуры папок.
2. Сохраните прежний адрес сайта (origin) и данные браузера — пять локальных слотов находятся в том же хранилище. Старые сохранения не требуют нового формата.
3. Обновите страницу после загрузки всех файлов. Новые sprites имеют новые имена; основной bundle подключён с версией 0.29.0.
4. Проверьте игру на PC и телефоне по списку в `docs/CHARACTER_ANIMATION_REPORT_RU.md`.

`character-preview.html` — дополнительный просмотр кадров, поворотов, инструментов и сна. Открывается через HTTP-сервер рядом с игрой. Он не читает и не меняет игровые сохранения.

Готовая сборка не требует Node.js. Для разработки: `npm ci`, `npm run build`, `npm run check`, `npm test`. Для локального HTTP-сервера можно выполнить `python -m http.server 8000`, затем открыть `http://localhost:8000/`.

В архиве есть исходники, Asset Manifest, тесты, точная исполняемая база 0.28.0, визуальные контрольные изображения и отчёт. `dev.html` — прежний изолированный режим тестирования; не используйте его для обычной игры.

Основной отчёт: `docs/CHARACTER_ANIMATION_REPORT_RU.md`. Список изменённых файлов: `docs/CHARACTER_CHANGED_FILES.json`. Задания генерации: `docs/CHARACTER_ASSET_PROMPTS.json`.
