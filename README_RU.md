# LAST BASE 0.24.0 — Этап 4: ресурсы и загрузка

Версия поверх принятой 0.23.1 с PC/Mobile controls. Новая структура assets, стабильные пути, metadata атласов и загрузка картинок по необходимости. Изображения сохранены без изменения байтов; игровые механики и управление сохранены. Этап 5 не начат.

## Как загрузить на GitHub

Распакуйте архив и загрузите **содержимое** в репозиторий. Для сайта нужны вместе `index.html`, `js/`, `styles/`, `assets/`. Для полного проекта сохраните также `src/`, `tools/`, `qa/`, `docs/`, `package.json` и `package-lock.json`.

Используйте целиком новую папку `assets/`. Папки старого выпуска `assets/v0190/` и `assets/v0200/` больше не используются: после успешного обновления их можно удалить из репозитория. Не удаляйте собственные дополнительные файлы, если вы добавляли их отдельно.

Сборка уже готова. Node.js на GitHub Pages или телефоне не требуется. Сохраните прежний адрес сайта: localStorage привязан к адресу. Для переноса между адресами используйте существующий экспорт/импорт saves. После обновления перезагрузите страницу полностью.

Локально запустите `python3 -m http.server 8080` и откройте `http://localhost:8080`.

## Что внутри

- `src/` — 61 секция JS; порядок в `src/manifest.json`.
- `js/game.js` и карта исходников — готовая сборка.
- `assets/manifest.json` — каталог; понятные папки внутри `assets/`.
- `docs/ASSETS_RU.md` — структура, замена файлов, атласы и кэширование.
- `docs/STAGE4_REPORT_RU.md` — итоговые проверки и замеры этого этапа.
- `docs/stage4-source.patch` — изменения относительно 0.23.1.
- `docs/CONTROLS_RU.md` — действующее управление.
- `qa/results/summary.json` — полный актуальный regression suite.
- `qa/controls-base/`, `qa/stage0/`…`qa/stage3/` — исторические эталоны; прежние отчёты в docs относятся к своим выпускам.

Обычную картинку можно заменить файлом с тем же именем, форматом и путём без изменения game logic. Для атласов обязательно сохраняйте расположение кадров либо обновите metadata и сборку. Семь исходных MP3 остаются отсутствующими; подробности в `assets/audio/effects/README_RU.md`.

## Разработка

```sh
npm ci
npm run build
npm run check
npm test
npm run bench
```

Node.js 20+. Зависимость Canvas нужна только тестам; сборка использует встроенные средства Node.js. Не редактируйте сгенерированный bundle вручную: правьте `src/` и `assets/manifest.json`, затем пересобирайте.

Замеры стенда не являются FPS телефона. Перед переходом к следующему этапу проверьте игру вручную по `docs/ASSETS_RU.md`.
