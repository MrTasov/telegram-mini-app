# LAST BASE 0.27.1 — corrective / gameplay UX patch

Готовая single-player игра на существующей архитектуре. [Отчёт об исправлениях и проверках](docs/CORRECTIVE_PATCH_RU.md).

Распакуйте ZIP целиком и загрузите его содержимое на GitHub с сохранением папок. Для игры нужны `index.html`, `js/`, `styles/`, `assets/`. Не открывайте HTML внутри архива. Сохраните прежний адрес сайта: пять слотов находятся в localStorage этого адреса. На телефоне Node.js не требуется.

Обычные игровые окна больше не останавливают мир. Через автоматические проходы можно идти одним кликом; главные ворота открываются при подходе по маршруту. Reload, выбор цели, quick slots и UI не отменяют обычное движение. Пустое loot-окно закрывается после забора последнего предмета. На внешней стене четыре лестницы, по одной на сторону.

У дрона отдельно показаны заряд и прочность. Для полевого ремонта нужен находящийся рядом дрон с прочностью выше нуля. Полностью сломанного дрона можно забрать в рюкзак, принести к станции, установить и починить кнопкой «Починить дрон». Нужны детали: одна на каждые 25 недостающих единиц прочности, с округлением вверх. Цена задаётся в `src/drones/companion.js`, `ITEM.drone014.drone.repair`.

`npm ci`, `npm run build`, `npm run check`, `npm test` — команды для разработчика. Тесты используют моделируемый DOM и native Canvas; ручная проверка телефона и Telegram остаётся необходимой.

`dev.html` — прежний изолированный режим проверки Дня X без записи в обычные saves. Для публичной версии не публикуйте `dev.html` и `dev/`. Настоящий multiplayer не добавлен. Исторические отчёты Этапов 6–7 относятся к 0.27.0; актуальный результат этого патча — в отчёте 0.27.1.
