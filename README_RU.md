# LAST BASE 0.39.0 — Stage H

Основа: принятая **0.38.0 Stage G**. [Подробный отчёт](STAGE_H_REPORT_RU.md)
и [контракты](docs/STAGE_H_CONTRACT_RU.md).

В физическом Command Core → Construction доступны Автоматическая турель,
Тяжёлая турель и Прожектор. Создание расходует материалы и кладёт отдельный
объект в реальную ячейку рюкзака. Для установки турелей выйдите во двор базы,
выберите объект в рюкзаке и установите через обычный preview с поворотом.
Прожектор можно разместить во дворе или в разрешённых помещениях Level 1.
Площадки ограничены периметром; ворота, лестницы и важные проходы защищены.

Взаимодействуйте с установленным объектом для загрузки патронов, ремонта,
улучшения, ON/OFF либо настройки направления прожектора. Направление головки
подтверждается отдельно от поворота корпуса. Pick Up требует прежнего
удержания 3 секунды и сохраняет тот же instance, состояние и боезапас.
Power включается локально, через Base Control в Core или Base Remote.
Для ремонта нужен молот в руках и железо; разрушенные объекты можно восстановить.

Панель Objectives компактнее, её свёрнутое состояние переживает переходы между
зонами в пределах сессии. Секторные кружки и подписи убраны с обычной карты;
архитектура секторов, POI и исследование мира сохранены.

Save Format **19**, миграция **18→19**, прежние миграции сохранены.
Старая HMG становится Тяжёлой турелью с тем же ID/боезапасом/уровнем.
Intro, Chapter 1 revision 6, Archive, Research и все принятые системы сохранены.

Запускайте через HTTP: `python -m http.server 8000`. Для сохранения доступа к
локальным сейвам используйте тот же адрес сайта/origin. Обновляйте весь пакет.
Сборка/QA: Node 20+, `npm install`, `npm run build`, `npm test`,
`npm run test:h`, `npm run bench:h`, `npm run package:h`.

Автотесты используют моделируемые DOM/WebAudio и настоящий Canvas2D.
Это не визуальная приёмка браузера на телефоне/Telegram и не измерение FPS
реального устройства. Ограничения и все результаты приведены в отчёте.

После Stage H разработка остановлена для ручной проверки. Stage I, Level 2,
Farm/Animals, Signal/Threat не начаты. Бой вне видимой сцены оставлен для I1.
