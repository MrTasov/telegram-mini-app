# LAST BASE — контрольный комплект Stage 0

Игра остаётся **0.20.0**. Это комплект исходного состояния и проверок. Для продолжения обычной игры ничего загружать на GitHub не требуется.

Начните с `LAST_BASE_Stage_0_Report_RU.md`. В нём краткий результат, ограничения и показатели. Подробные сценарии — `audit/SCENARIOS_RU.md`, связи систем — `audit/DEPENDENCIES_RU.md`.

`baseline_0.20.0/index.html` и `baseline_0.20.0/assets/` — точная копия текущего релиза. Данные Stage 0 находятся рядом, а не встроены в игру. Не запускайте `source/build.py` для повторения Stage 0: это прежний скрипт сборки игрового патча, для анализа он не нужен.

## Повторение проверок разработчиком

Нужен Node.js (использовался 24.19.0) и `@napi-rs/canvas` 0.1.100. Зависимость указана в `package.json` исключительно для диагностических скриптов; браузерная игра от Node/npm не зависит. В обычном локальном окружении установите её командой `npm install` в этой папке. В среде с уже подготовленными зависимостями дополнительная установка не нужна.

Запускать из корня комплекта, последовательно:

```sh
node tools/inventory.cjs
node tools/behavior.cjs
node tools/regressions.cjs
node tools/performance.cjs
node tools/verify.cjs
```

Скрипты перезаписывают только отчёты/фикстуры своего комплекта, сохраняя `baseline_0.20.0`. Предыдущие результаты перед сравнением скопируйте отдельно. Исходные регрессионные тесты запускаются в собственной временной папке.

Дополнительная сверка существующего проекта:

```sh
node tools/verify.cjs --original /absolute/path/to/original/release
```

`reports/integrity.json` фиксирует результат. `behavior.json` отдельно содержит несовпадения (`OBSERVED_FAILURE`) и ошибки стенда (`ERROR`); не превращайте их в PASS изменением ожидаемых значений без расследования.

Сценарии производительности используют фиксированные часы, seed и прогрев. Они не измеряют браузерный FPS, CSS, мобильный GPU или сетевую загрузку. Нужные проверки телефона перечислены отдельно, их нельзя считать выполненными по этим JSON.

Контрольные saves созданы для тестов, не являются прогрессом игрока и не должны импортироваться поверх личных сохранений. Фикстуры содержат полные данные мира; их календарные времена нужно учитывать при проверке офлайн-роста.

Stage 1 не выполнен и не начинается этими скриптами.
