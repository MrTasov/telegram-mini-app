# LAST BASE 0.28.0 — World / Farm / Drone / Resources

Патч на стабильной версии 0.27.1. [Изменения, баланс, миграции и результаты проверок](docs/WORLD_FARM_RESOURCES_RU.md).

Распакуйте ZIP и загрузите его содержимое на GitHub с сохранением папок. Для игры нужны `index.html`, `js/`, `styles/`, `assets/`. Готовая сборка включена. Не открывайте HTML внутри архива. Сохраните прежний адрес сайта: пять слотов находятся в localStorage этого адреса. На телефоне Node.js не требуется.

Добавлены естественные группы деревьев/камня/руды и четыре угольные зоны; цепочка уголь → порох → патроны. Через пять грядок можно ходить, посадка не требует предметов. У каждой грядки свой полив, новый бак — 500 л. Коровы занимают шесть постоянных стойл. Интерфейс дрона стал компактнее, возврат на станцию использует автоматические проходы. Inventory Pin удалён; quick slots рюкзака и закрепление рецептов сохранены.

В старом сохранении вода не пополняется бесплатно. Лишние старые коровы сохраняются в резерве: кнопку возврата можно использовать, когда освободится стойло. После настоящей блокировки маршрута дрон ждёт; устраните препятствие и повторите «На станцию».

Разработчику: `npm ci`, `npm run build`, `npm run check`, `npm test`. Баланс находится в `src/config/gameplay.js`. `npm run bench:world-farm` сравнивает native Canvas/VM с 0.27.1; это не замер FPS реального телефона.

Для публичной версии не публикуйте `dev.html` и `dev/`: это прежний изолированный режим проверки Дня X. Следующий gameplay/content patch не начат. Текущая версия оставлена для ручной проверки на PC и Mobile.
