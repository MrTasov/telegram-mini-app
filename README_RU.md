# LAST BASE 0.40.0 — H Corrective + Stage I1

Основа: принятая **0.39.0 Stage H**. [Подробный отчёт](STAGE_I1_REPORT_RU.md),
[контракты](docs/STAGE_I1_CONTRACT_RU.md).

Выберите переносимое оборудование в Inventory → «Разместить». Preview появится
рядом с Player в настоящей игровой сцене. Перемещайте его мышью или touch,
вращайте кнопкой либо R; подтвердите кнопкой либо Enter. Escape отменяет
preview, оставляя тот же предмет в рюкзаке. Упаковка установленного объекта
по-прежнему требует удержания 3 секунды. Collision, wall-tight, поворот,
защита ворот/проходов и same-instance re-placement сохранены.

Автоматическая и тяжёлая турели не видят и не стреляют через целые стены.
Открытый проход или разрушенная стена открывают физическую линию огня.
Прежняя турель на стене может стрелять наружу. Стоимость, урон и Research
доступ Stage H сохранены. Прожектор сохраняет независимое направление головки.

В Core → Base Control и Base Remote одни и те же компактные переключатели.
Освещение не отключает станки. Настройка электрической двери «Автооткрытие»
отделена от питания: ВЫКЛ запрещает открытие от приближения; ВКЛ разрешает его
при исправной двери и наличии питания. Ручное взаимодействие остаётся.
Настройка сохраняется; занятый проём не закрывается на Player/Drone.

Intro New Game показывается на весь экран с сохранением 16:9, без обычного
HUD и стандартных video controls. Внизу справа — «ПРОПУСТИТЬ», учитывающая
safe areas. Официальный видеофайл не изменён. Skip/конец продолжают Chapter 1;
Continue не повторяет Intro. Archive остаётся доступен для повторного чтения.

I1 продолжает существующую симуляцию: турели, нападение, урон стенам и
оборонному оборудованию действуют, когда Player находится в бункере или
другом секторе. Возвращение показывает результат. Далёкие враги, включая идущих к базе участников Day X,
обновляются реже до входа в активную область; второй цикл симуляции не создан. Power, топливо,
батарея и производство используют прежние владельцы состояния.

Save Format **20**, migration **19→20** плюс все ранние migrations.
Сохраняются pending attacks, fuse/leap и cooldown турелей; загрузка не
рассчитывает нападения за время закрытой игры. В явной одиночной паузе,
Intro, скрытой вкладке и Main Menu мир по-прежнему приостановлен.
Обычные окна Inventory/Core и смена зоны не останавливают общий бой.

Запуск: `python -m http.server 8000`, затем открыть адрес этого сервера.
Обновляйте папку целиком и сохраняйте прежний origin сайта для browser saves.
Для разработки: Node 20+, `npm install`, `npm run build`, `npm test`.
Проверки I1: `npm run test:i1`; замеры: `npm run bench:i1`.

Результаты находятся в `qa/results`. Native Canvas и модель DOM не заменяют
ручную проверку на PC/телефоне/Telegram. I2, Signal/Threat, Level 2 и Farm/Animals
не начаты; после этой сборки требуется ручная приёмка.
