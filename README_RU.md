# LAST BASE 0.30.0 — Bunker Level 1 Rework R1

Отдельный патч поверх **LAST_BASE_0.29.0_Audio_Pass_Recovery_1.zip**. Готовая игра, исходники, изображения, 58 звуков, лицензии и тесты включены полностью.

1. Распакуйте ZIP. Разместите `index.html`, папки `js/`, `styles/`, `assets/` с сохранением структуры. Для GitHub Pages можно загрузить весь проект в корень выбранной ветки.
2. Сохраните прежний origin сайта и данные браузера. Формат save автоматически обновляется до **4**. Старые слоты читаются, позиции Player/Drone переносятся в новую геометрию. Перед ручной проверкой сохраните экспорт важного слота; старые версии игры не понимают новый формат 4.
3. После загрузки всех файлов обновите страницу. Cache-tag игры: `0.30.0-bunker-level1-r1`.
4. Нажмите кнопку входа или коснитесь игрового экрана: звук включается после пользовательского действия, как в предыдущей версии.
5. Проверьте новый Level 1 по списку в `BUNKER_LEVEL1_REWORK_RU.md`.

Для готовой игры Node.js не требуется. Локальный запуск: `python -m http.server 8000`, адрес `http://localhost:8000/`.

Для разработки: Node.js 20+, `npm ci`, `npm run build`, `npm run check`, `npm test`. Опционально: `LAST_BASE_TEST_JOBS=3 npm test`. Только R1: `npm run test:bunker`. Визуальные кадры: `node qa/bunker-visuals.cjs`. Сравнение CPU до/после: `node qa/bunker-performance.cjs`, без параллельного запуска других тестов.

В центральном зале находится постоянный Command Core. Семь окружающих комнат сохраняют свободное пространство. Лестница вверх ведёт на поверхность; лестница вниз закрыта. Farm, Cows, Chickens и производство корма сохранены, но полностью поставлены на паузу, включая время вне игры. Данные не удаляются и не обнуляются.

Итоговый отчёт: `BUNKER_LEVEL1_REWORK_RU.md`. Изменённые файлы и хеши: `BUNKER_LEVEL1_CHANGESET.json`. Все группы тестов: `qa/results/summary.json`. Изображения: `qa/results/bunker-visuals/`. Performance: `qa/results/bunker-performance.json`.

Лицензии звуков: `assets/audio/CREDITS.md`. Запись курицы — CC BY 3.0, обработанная запись коровы — CC BY-SA 3.0. Все готовые WAV включены; повторная загрузка не требуется. Новый asset Command Core описан в `docs/BUNKER_COMMAND_CORE_ASSET.md`.

`character-preview.html` — прежний просмотр персонажа. `dev.html` — изолированный режим разработки. Исторические отчёты и test fixtures сохранены. Stage A, Level 2 и Building/Placement в этот патч не входят.
