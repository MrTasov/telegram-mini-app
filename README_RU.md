# LAST BASE 0.31.0 — Stage A

Полная GitHub-ready сборка поверх вручную принятой **0.30.1 Bunker Level 1 Rework R2**.
Добавлены основа кампании/целей и минимальный Command Core. Планировка R2,
постоянный центр Core (1210, 510), его графика и коллизия сохранены.

## Запуск и обновление

1. Распакуйте ZIP. На GitHub загрузите распакованное содержимое, сохранив структуру
   `index.html`, `js/`, `styles/`, `assets/`. Для GitHub Pages можно загрузить весь
   проект в корень выбранной ветки. Готовая игра уже собрана; Node.js для неё не нужен.
2. Для сохранения локальных слотов используйте прежний адрес сайта/origin и
   данные браузера. Старые saves автоматически мигрируются в **SaveFormat 6**.
   Встроенный экспорт важного слота позволяет отдельно сохранить исходную копию;
   предыдущие версии игры формат 6 не читают.
3. Обновите страницу после загрузки всех файлов. Cache-tag: `0.31.0-stage-a`.
4. Локально: `python -m http.server 8000`, затем `http://localhost:8000/`.

## Что проверить

В центральном зале подойдите к Командному центру. Вкладки: **Главы** и **База**.
Цепочка «Освоение базы»: запустить генератор → добыть новую руду на поверхности →
вернуться к включённому Core и подтвердить переход. Перемещение старой руды из
ящика не засчитывается. Переход не происходит сам и не выдаёт повторных наград.

Core использует 0,05 кВт из прежней сети; его питание зависит от переключателя
устройства, контура зала и доступной мощности. Просмотр целей через tracker
работает и без питания, но дистанционное подтверждение недоступно. Research и
Achievements открывают прежние экраны с прежним прогрессом.

Семь комнат, две лестницы, оборудование, Drone Station, управление и Day X
сохранены. Farm/Cows/Chickens остаются в полной simulation pause. Stage B,
Level 2, Building/Placement, повреждённый New Game и новые Research не начаты.

Подробный список ручной проверки и результаты — `STAGE_A_REPORT_RU.md`.
Контракты/границы — `docs/STAGE_A_CONTRACT_RU.md`. Полный Roadmap также включён в docs.

`node --expose-gc qa/campaign-performance.cjs` — запускать отдельно от тестов.

релизы; они не являются результатами текущей проверки. Исходные fixtures сохранены.
