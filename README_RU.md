# LAST BASE 0.27.0 — Этапы 6 и 7

World Events / День X и архитектурная подготовка к co-op поверх принятого Main Menu patch 0.25.3. Игра остаётся single-player. Настоящий multiplayer не реализован. Готовая сборка, исходники, контрольные saves и автоматические проверки включены.

## Запуск

Распакуйте ZIP полностью. Для GitHub Pages обновите содержимое проекта с сохранением папок. Рабочая игра использует `index.html`, `js/`, `styles/` и `assets/`; Node.js на телефоне или сайте не нужен. Сохраните прежний адрес сайта для доступа к существующему localStorage. После обновления перезагрузите страницу и проверьте номер **0.27.0**.

Локальный запуск: `python3 -m http.server 8080`, затем `http://localhost:8080`. Главное меню, общие Settings, EN/RU и AUTO/PC/MOBILE сохранены. PC использует прежнее перемещение мышью; управление не заменено на WASD.

## День X

Каждый десятый день, `day % 10 === 0`: начало **00:00**, окончание **06:00**. В принятой версии усиление действовало весь десятый день; окно изменено по точному требованию Этапа 6. Значения HP, урона, скоростей, cooldown, специальных механик и spawn сохранены. Новые визуальные эффекты и звуки не добавлены.

Для ручной проверки откройте **`dev.html`** вместо обычной страницы. Это отдельный developer entry: он читает копию текущих слотов в память и изолирует все дальнейшие записи. Выберите копию сохранения или New Game, затем используйте:

- **START X EVENT** — принудительное включение через общий WorldEvents.
- **STOP X EVENT** — принудительное выключение.
- **CALENDAR / КАЛЕНДАРЬ** — убрать override и вернуться к календарному правилу.
- **DAY 9 · 23:59** — естественный переход через ближайшую игровую минуту.
- **DAY 10 · 05:59** — проверить завершение в 06:00.

Кнопки изменения времени действуют только в тестовой копии. Перезагрузка `dev.html` отбрасывает её изменения. Обычный `index.html` не загружает developer panel и не предоставляет debugOverride. Для обычной production-публикации достаточно четырёх игровых путей выше; `dev.html` и `dev/` — инструменты проверки, их можно не публиковать.

## Сохранения и границы

Пять прежних слотов и старые saves поддерживаются. `saveVersion: 2` добавляет служебные ID игрока/врагов и ссылку цели дрона через миграцию `identity027`; ключи хранилища и игровой прогресс сохраняются. Новые saves не предназначены для загрузки в старой сборке 0.25.3. Язык и Control Mode остаются отдельными настройками.

В игре один player и один loop. Сетевых соединений, сервера, комнат или аккаунтов нет. Ограничения текущих global player/scene, combat, inventory и многозонной simulation перечислены в отдельном отчёте.

## Разработка

```sh
npm ci
npm run build
npm run check
npm test
npm run bench:stages
```

Node.js >= 20; Canvas-зависимость нужна только тестам. Не запускайте regression suite и benchmark одновременно. Редактируйте `src/`, затем пересобирайте `js/game.js`/source map через `src/manifest.json`. Fingerprint исходников не обновляется автоматически тестами.

Изображения, атласы, фон меню, styles и каталоги локализации сохранены байт в байт. Семь необязательных звуков отсутствовали в исходной игре; новые missing paths не добавлены. Замеры VM/Canvas не являются FPS или памятью физического телефона. Финальная сборка ожидает ручной проверки PC/Mobile.
