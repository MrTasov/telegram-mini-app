# LAST BASE 0.23.0 — Этап 3

Этап «Обобщать системы по очереди» завершён поверх принятой 0.22.0: предметы / инвентарь / боеприпасы / оружие → враги → дрон / турели → разрушаемые объекты / улучшения. Этап 4 «Ресурсы и загрузка» не начат.

## Как загрузить на GitHub

Распакуйте архив и загрузите **содержимое** в репозиторий. Для сайта нужны вместе `index.html`, `js/`, `styles/`, `assets/`. Для полного проекта сохраните также `src/`, `tools/`, `qa/`, `docs/` и `package.json`.

Сборка уже готова. Node.js на GitHub Pages или телефоне не требуется. Сохраните прежний адрес сайта: localStorage привязан к адресу. Старые saves загружаются автоматически; для переноса между адресами есть экспорт/импорт.

Локально:

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Что внутри

- `src/` — 56 исходных JS-секций; порядок в `src/manifest.json`.
- `js/game.js`, `js/game.js.map` — готовая сборка и карта исходников.
- `styles/`, `assets/` — прежний CSS и 99 изображений без изменений.
- `docs/STAGE3_RU.md` — определения, совместимость, границы этапа и ручная проверка.
- `docs/REPORT_RU.md` — итоговые проверки и производительность.
- `docs/stage3-source.patch` — точные runtime-изменения относительно принятой 0.22.0.
- `qa/stage0/`, `qa/stage1/`, `qa/stage2/` — сохранённые контрольные данные.
- `qa/results/summary.json` — итог всего regression suite.
- `qa/results/stage3-part-1/` … `stage3-part-4/` — проверки после последовательных частей.

Редактируйте исходники в `src/`, затем пересобирайте:

```sh
node tools/build.cjs
node tools/build.cjs --check
```

Остаётся один classic script с прежним порядком исполнения. React, Vite и новая система загрузки не добавлены.

## Проверки

Нужны Node.js 20+ и тестовая зависимость `@napi-rs/canvas` 0.1.100:

```sh
npm install
npm test
npm run bench
```

Полный suite включает прежние регрессии, взаимодействия мышью/касаниями, save/load, защиту слотов, сравнение баланса, сравнение с 0.21.0 и принятой 0.22.0, проверки расширения через временные определения. Эти определения не попадают в runtime игры.

Стенд использует VM, модель DOM и Canvas2D. Это не измерение FPS телефона. Семь исходных MP3 отсутствовали уже в Stage 0; перечень сохранён в отчёте. Проверьте игру вручную по списку в `docs/STAGE3_RU.md` перед следующим этапом.
